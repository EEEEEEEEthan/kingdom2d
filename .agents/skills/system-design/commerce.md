# 商业建筑经营

> 工作场所（铁匠铺、酒馆、澡堂等）的记账主体、运营资金与雇员关系。占格、服务等级见 [structures.md](structures.md)；净收入估值见 [building-valuation-calculator.md](building-valuation-calculator.md)。

### 商业建筑为经济单位

- **规则**：每栋**商业建筑实例**是独立**经济单位**，与角色并列持有货币与物资；近一年**净收入**按**该建筑实例**统计，计入商业估值。
- **说明**：
  - 建筑主人（角色）不直接占有营业流水；通过「运营储备」与所有者注资/分红与建筑账本交互
  - 住房实例不作为本节的经营单位（住房估值走实际住房等级）

### 建筑所有者

- **规则**：每栋商业建筑有且仅有一名**建筑主人**（角色）；主人负责向建筑**注入运营资金**、在储备超额时**收取分红**；主人**不**因拥有建筑而自动承担店内劳动（须走雇员岗位）。
- **说明**：
  - 建筑主人确立时机见 [structures.md](structures.md)（D03 待决）；本节假定实例已存在且主人已定
  - 主人可兼任该建筑雇员，见「商业雇员」

### 运营储备

- **规则**：建筑须维持相当于 **7 个游戏日**运营支出的**运营储备**（货币）；储备**低于**该目标时，建筑主人有义务向建筑**注资**补足；储备**高于**该目标时，主人**提走超出部分**作为分红。
- **说明**：
  - 「7 日运营支出」按该建筑类型配置的**日均运营成本**估算（含协定日薪、物料、固定开销等；具体项实现期配置）
  - 注资与分红在实现约定的**日更时刻**结算（时刻见 [open-decisions.md](open-decisions.md) X15）
  - 储备不足且主人无法注资时，按欠薪规则解除雇员，见 [characters.md](characters.md)「雇员薪酬结算」

### 商业雇员

- **规则**：商业建筑**雇佣**雇员（非建筑主人直接向人发薪）；岗位空缺时由**建筑主人**代为发起「雇佣选人」，**雇主实体为建筑实例**；薪酬从建筑运营储备支付。
- **说明**：
  - 选人、日薪底价、任职条件、挖墙脚、协定日薪锁定等同 [characters.md](characters.md)「雇佣选人」「雇员薪酬结算」
  - **允许建筑雇佣其主人**（便于劳动获益与净收入统计）；**玩家 UI 不展示「自己雇佣自己」**
  - 数据与流程须支持**多雇员岗位**，**首版每栋商业建筑仅开放 1 个雇员岗**
  - 与**建造雇工**区分：工地建筑工由**建造责任方**（角色）雇，雇主为角色，见 [structures.md](structures.md)「建造施工流程」

### 收支记账归属

- **规则**：商业建筑实例的**营业收入**与**营业支出**记入该建筑账本；雇员薪酬、物料采购、服务收入等均属建筑收支，用于净收入统计与运营储备。
- **说明**：
  - 收支事件明细口径见 [open-decisions.md](open-decisions.md) X16
  - 角色私人消费、早市 C2C 交易不计入建筑净收入（除非经建筑柜台成交，待「营业与消费」定案）
