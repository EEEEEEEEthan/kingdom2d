# 建筑运营

> 建筑**经济单位**的记账、税收、床位租约、运营储备与雇员（经济单位模型见 [economy.md](economy.md)）。占格、服务等级见 [structures.md](structures.md)；创值与估值见 [building-valuation-calculator.md](building-valuation-calculator.md)。

### 建筑为经济单位

- **规则**：每栋**建筑实例**是一种**经济单位**（见 [economy.md](economy.md)）；持有建筑账本；**创值**按售品与床位租金实收统计，**创值·最近一年**计入建筑估值。
- **说明**：
  - 建筑主人（角色）不直接占有建筑流水；通过「运营储备」与**注资/分红**与建筑账本交互（经济单位间资金注入，见 [economy.md](economy.md)「经济交互」）
  - **雇员**、**协定日薪上限**、**创值预测**见 [economy.md](economy.md)「雇员与协定日薪上限」「创值预测」
  - 铁匠铺、茅舍等均为建筑，**同一套**运营与估值流程；差异由类型配置表达（床位数、雇员岗、营业能力等）

### 建筑创值

- **规则**：建筑**创值** = **实际出售商品**收入 + **床位租金**收入；与账本**净收入**（收入 − 支出）**分离**。
- **说明**：
  - **售品收入**：经店内/窗口成交、**铺面代摊**等**实际售出**并记入建筑账本的货款（未售出库存**不计入**创值）
  - **床位租金**：已占床按**挂牌日租**实扣并入账本的金额，**含外租与主人自租**（自租 = 主人按挂牌价「租给自己」，见「床位租约」；UI 不展示自租，但创值**计入**）
  - 生产完成写入 [economy.md](economy.md)「生产行为记录」；仅成交/收租时刻计入创值
  - 首版生产类建筑**不开**床位出租；未来若开放，售品与床位租金**叠加**计入创值

### 建筑类型配置

- **规则**：每种建筑类型在配置中声明**床位数**、**日税**（向领主缴纳）、是否开放**雇员岗**、是否具备**上岗窗口**与**铺面代摊**等；**床位数可为 0**（示例：铁匠铺无床位）。
- **说明**：
  - 具备**配置住房等级**的类型参与**实际住房等级**与**服务等级**判定，见 [structures.md](structures.md)「住房等级与服务等级」
  - 具体类型列表与数值实现期配置

### 建筑主人

- **规则**：每栋建筑有且仅有一名**建筑主人**（角色）；主人负责向建筑**注入运营资金**、在储备超额时**收取分红**；主人**不**因拥有建筑而自动承担店内劳动（须走雇员岗位，若该类型开放雇员岗）。
- **说明**：
  - 建筑主人于**放置地基**时确立，见 [structures.md](structures.md)「建筑主人确立」
  - 主人可占用本建筑**床位**并兼任雇员，见「床位租约」「建筑雇员」

### 运营支出与运营储备

- **规则**：建筑**日均运营支出** = **日税** + **雇员佣金**（按该类型**满员**岗位与协定日薪估算）+ **原材料消耗成本**（按**满效率**日产量 × 各原料**当日市价**）。**无雇员岗、无生产**的类型仅计日税。建筑须维持相当于 **7 个游戏日**运营支出的**运营储备**（货币）；储备**低于**目标时，建筑主人须向建筑**注资**补足；储备**高于**目标时，主人**提走超出部分**作为分红。
- **说明**：
  - 日税由**税务官**上门收取，见「日税与税务官」；雇员薪酬与原料采购自储备支付，见 [characters.md](characters.md)「雇员薪酬结算」
  - **建造可负担判定**、**商业投资盈利估算**中的运营支出按**满员满效率**计（见 [structures.md](structures.md)「建造可负担判定」）
  - 实际经营中原料按**实际产量**扣费，见「建筑自动生产」
  - 注资与分红在**游戏日批处理**中、薪酬结算之后执行（顺序见 [time.md](time.md)「游戏日批处理顺序」）
  - 储备不足且主人无法注资时：有雇员则按欠薪解除雇佣

### 床位租约

- **规则**：**床位数 > 0** 的建筑，每个床位同一时刻最多一名**租约人**（角色）；**建筑主人**占用本建筑床位视为**自住**（见 [rent-willingness-calculator.md](rent-willingness-calculator.md)「自住」），**不**走租赁寻租流程，但**仍**按**挂牌日租**扣款入账（UI 不展示自租）。
- **说明**：
  - 租约：**日付**、无押金；角色**随时可退**；占格**清场**时该建筑全部租约**立即终止**
  - 租约人**实际住房等级** = 该建筑实例的**实际住房等级**，用于 [needs.md](needs.md) 生活水平判定
  - 续租/离店/寻租由 [rent-willingness-calculator.md](rent-willingness-calculator.md) 判定，于游戏内 **12:00** 执行（见 [time.md](time.md)「租意愿判定时刻」）

### 日税与税务官

- **规则**：具备**日税**的建筑类型，由**税务官**（场内收税代理）于**工作**时段逐栋上门收取当日**日税**；税款自建筑运营储备（或建筑账本货币）划入领主钱包。
- **说明**：
  - 税务官收款时若建筑**支付不起**全额日税 → 对该建筑执行**拆毁**（占格归领主，见 [structures.md](structures.md)「建筑拆毁」「占格清场」）；拆毁瞬间账本内剩余资源按「建筑拆毁」归**建筑主人**
  - 收税在**工作**时段执行，晚于 **0:00** 批处理与**早市**；破产拆毁影响**次日**市价快照

### 床位挂牌租金

- **规则**：每个**床位**（含空床与已租床，**同一建筑各床同价**）维护**挂牌日租**；**每个游戏日**更新一次：
  1. **新竣工**建筑：挂牌价 = 同**实际住房等级**（或等级档位）在场建筑的挂牌日租**算术平均**；若无样本，取该等级 **R_min** 与 **R_max** 的**中点**（区间见 [rent-willingness-calculator.md](rent-willingness-calculator.md)「等级租金区间」）。
  2. **日更调整**：**未满员**（存在空床）→ 挂牌价 × **0.99**（**−1%**）；**满员**（无空床）→ 挂牌价 × **1.01**（**+1%**）。
  3. **clamp**：调整后的挂牌价限制在 **[R_min, R_max]**（该等级全场区间）。
- **说明**：
  - **无议价**；租客按挂牌价日付，收入记入建筑账本**租金收入**
  - 空床不产租金收入，**日税**仍由建筑账本支出
  - **已废止**：固定「利润系数 × 日税/床」定价公式

### 建筑雇员

- **规则**：开放**雇员岗**的建筑类型由**建筑实例**作为雇主**雇佣**多名雇员（按类型配置**满员人数**）；每类建筑配置**具名雇佣职业**（示例：铁匠铺 → **铁匠**）；岗位空缺时由**建筑主人**代为发起「雇佣选人」填补空岗；薪酬从建筑运营储备支付。此类岗位为**雇佣职业**，**必须**绑定该建筑实例的**上岗窗口**。
- **说明**：
  - 选人、日薪底价、协定日薪上限、挖墙脚、空岗立即再雇、协定日薪锁定等同 [characters.md](characters.md)「雇佣选人」「协定日薪上限」「雇员薪酬结算」
  - **允许建筑雇佣其主人**；**玩家 UI 不展示「自己雇佣自己」**
  - 在岗雇员数 / 满员人数 = **在岗率**，影响「建筑自动生产」效率；无岗类型满员为 0
  - 与**建造雇工**区分：工地建筑工由**建造责任方**（角色）雇，雇主为角色，见 [structures.md](structures.md)「建造施工流程」

### 建筑产出商品

- **规则**：每种可生产的建筑类型在配置中声明**唯一产出商品**（具体资源品种）及**满效率日产量**、**单位产量原料清单**、**库存阈值**。
- **说明**：
  - **酒馆**产出 **[酒馆服务]**，标签 **【食物】**、**【服务】**；生产节拍快，**库存阈值**配置偏低
  - **澡堂**产出 **[澡堂服务]**，标签 **【服务】**（类型可配置，首版可不实现）
  - 首版可生产商业建筑先实现**酒馆**；铁匠铺等后续扩展
  - 品种与标签登记见 [economy.md](economy.md)「资源与标签」

### 建筑库存阈值

- **规则**：凡有产出商品的建筑实例维护**库存阈值**（按类型配置，可含领主/主人可调项）；库存**超过阈值**的部分视为可向市场释放的盈余，可经**铺面代摊**或**店内成交**进入流通；**不超过阈值**的部分保留在建筑库存内，不参与早市代摊挂出。
- **说明**：
  - **领主（玩家）**可调整建筑库存阈值（调高→更易释货、压低→更易囤积），见 [economy.md](economy.md)「领主（玩家角色）」
  - 阈值仅约束「自动流向市场」的库存量；雇员在岗时的**主动成交**仍可在窗口内消耗任意可用库存
  - 具体默认值与可调范围按建筑类型配置；酒馆阈值宜低以匹配快产出

### 建筑自动生产

- **规则**：开放生产的建筑在**上岗窗口**覆盖的时段内**自动生产**其配置的产出商品；**实际日产量** = **满效率日产量** × **在岗率**（当前在岗雇员数 / 满员雇员数）。
- **说明**：
  - 示例：满员 4 人、在岗 2 人 → 在岗率 50% → 日产量为满效率的 50%
  - 原料按**实际产量**比例从建筑账本扣费（品种与数量按配置清单折算）
  - 产出入库**建筑库存**；【服务】类须在窗口内由雇员在岗接待成交（见「上岗窗口与营业」「早市铺面代摊」）；实物类可经铺面代摊或店内成交
  - 超出「建筑库存阈值」的盈余按上节进入可流通/可代摊池
  - 建筑被动产出**不计入**雇员个人创值（雇员创值为佣金）；**售出**后货款计入建筑创值与账本收入

### 收支记账归属

- **规则**：建筑实例的**收入**（**床位租金**、店内/窗口**服务与生产收入**、**铺面代摊**等）与**支出**（**日税**、**雇员薪酬**、物料采购等）记入该建筑账本，用于**运营储备**与注资/分红；**创值**取其中售品与床位租金实收子集（见「建筑创值」）。
- **说明**：
  - 收支事件明细口径见 [open-decisions.md](open-decisions.md) D13
  - 角色私人早市 C2C 交易不计入建筑账本；经**建筑柜台**或**铺面代摊**成交的计入该建筑收入
  - 主人自租的床位租金与外租**同口径**计入建筑创值（UI 不单独展示自租）

### 早市铺面代摊

- **规则**：具备代摊能力的建筑，在**早市**时段可将**建筑库存**中的适销实物挂出**铺面代摊**；**无人值守**；成交收入记入该建筑账本。
- **说明**：
  - 与角色个人摆摊并列，同属 [economy.md](economy.md)「早市」
  - **服务类**产出不可代摊，须在「上岗窗口」内由雇员在岗成交

### 上岗窗口与营业

- **规则**：开放**上岗窗口**的建筑类型配置窗口起点与时长（= 全场**标准上岗时长**，见 [time.md](time.md)）；窗口内雇员须在岗，执行生产或服务，并接待**有人值守**的店内成交。
- **说明**：
  - 无上岗窗口的类型（典型：纯住宅）不走本流程
  - 建筑工施工上岗不走本窗口，见 [structures.md](structures.md)「建造施工流程」
