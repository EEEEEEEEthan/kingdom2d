# 建筑 / 选址

## 已定决策

### 建筑分类

- **状态**：已定
- **规则**：建筑分「工作场所」与「住房」两类。
- **说明**：
  - 工作场所示例：铁匠铺
  - 住房示例：茅舍及更高级住宅
  - 具体类型列表与配置尚未定义

### 建造选址：先空地

- **状态**：已定
- **规则**：角色需要某类建筑时，先在地图上寻找满足该类型条件的空地；条件满足方可自建。
- **说明**：
  - 「空地」指可占格且通过该建筑类型选址规则的位置（与代码现状的差异：当前仅检查格空，邻域/地形等规则待实现）
  - 高级住房等类型可要求周边存在指定设施（邻域规则按类型配置）
- **开放问题**：
  - 空地是否排除环境物占格（橡树、灌木、旌旗等）？
  - 各建筑类型的邻域/地形规则表？

### 无空地则购置占格权

- **状态**：已定
- **规则**：工作场所与住房均采用同一逻辑：找不到符合条件的空地时，改为向他人购置既有建筑所占格位。
- **说明**：
  - 购置对象是当前格上的建筑实例及其占格权，不是入住或使用原建筑功能
  - 住房与工作场所无不同的购置分支

### 购置即拆后自建

- **状态**：已定
- **规则**：购置的含义是：付价取得占格权 → 拆掉原建筑 → 在同一格建造自己的目标建筑。
- **说明**：
  - 不存在「买下后继续当铁匠铺/继续当别人的茅舍用」的玩法路径
  - 卖方失去该格建筑；买方获得该格并在拆除后自建
- **开放问题**：
  - 拆毁是否消耗物料/劳动时间？
  - 卖方是否必须同意，还是存在强制价/市价？
  - **购置对价（价格）如何计算？**（见 [economy.md](economy.md) 商品市价框架，占格权交易可能不适用同质流通商品统计）
