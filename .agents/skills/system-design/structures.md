# 建筑 / 选址

### 建筑分类

- **规则**：建筑分「工作场所」与「住房」两类。
- **说明**：
  - 工作场所示例：铁匠铺
  - 住房示例：茅舍及更高级住宅
  - 具体类型列表与配置尚未定义

### 多格占地建筑

- **规则**：部分建筑类型占**多个连续（或按配置相邻）格子**；选址与占格须一次性满足该类型对全部占格的要求。
- **说明**：
  - 占格可混合「须向领主购地的空地」与「须向他人购置并拆除的已占格」
  - 角色可为同一栋多格建筑规划**组合方案**（比价后选取总成本最优者），见「组合建造方案与领主审批」
  - 与代码现状的差异：当前为一格一建筑实例，多格占地待实现
- **开放问题**：见 [open-decisions.md](open-decisions.md) **B5**、**B2**

### 建造施工流程

- **规则**：完成占地与权属安排后，建造须依次经历：**放置地基 → 填充材料至满 → 雇佣建筑工施工至竣工**；竣工建筑只能由建筑工完成最后施工阶段。
- **说明**：
  - 前置步骤含向领主购地/审批、购置他人建筑并拆除、组合方案整单执行等，见上文各节
  - 材料种类、数量、填料耗时尚未定义
  - 材料填满后触发「雇佣建筑工」；雇谁、薪酬见 [characters.md](characters.md)「雇佣建筑工」「雇员薪酬结算」
  - **每名角色作为建造责任方**，同一时间仅允许**一处**「建造中」工地（含地基/填料/待施工阶段）；第二处须等当前工地竣工或取消
  - 与代码现状的差异：当前建造为放置即完成，无地基/材料/雇工阶段
- **开放问题**：见 [open-decisions.md](open-decisions.md) **B4**、**X7**；受雇建筑工是否可同时参与多处施工（P2）

### 建造选址：先空地

- **规则**：角色需要某类建筑时，先在地图上寻找满足该类型条件的空地；条件满足后须向领主**购得该格土地所有权**（永久买断）并经领主同意，方可在该格建造。
- **说明**：
  - 「空地」指可占格且通过该建筑类型选址规则的位置（与代码现状的差异：当前仅检查格空，邻域/地形等规则待实现）
  - 高级住房等类型可要求周边存在指定设施（邻域规则按类型配置）
  - **向领主购地仅适用于空地路径**；向他人购置占格（拆后自建）不走领主售地，见「无空地则购置占格权」
- **开放问题**：见 [open-decisions.md](open-decisions.md) **X8–X9**

### 向领主购地与领主审批

- **规则**：角色在空地建造前，须向领主（玩家）申请**购买该格土地所有权**；领主同意且申请仍有效时，按领主设定的**购地价**完成永久买断（申请者 → 领主，见 [economy.md](economy.md)），随后可在该格建造。
- **说明**：
  - **设定上**双方可有土地契约；**游戏中简化**：不实现「地契」道具、库存或独立契约界面，仅以待办审批 + 货币交易表示购地
  - 购地为**永久买断**，非按次或临时租用；该格土地所有权归购买者（建筑产权另计，见「领主收回占格」）
  - 申请进入界面**待办队列**：队列中插入一项可点按钮
  - 点开展开详情界面，说明例如：「{角色}希望在{位置}建造{建筑类型}，须向领主购地」
  - **拒绝**：不成交、不转移土地所有权，该次申请结束（角色后续行为待定）
  - **同意**：执行前再次验证，防止申请**过期**；校验失败则不成交（等同拒绝或需提示原因，实现待定）
  - **过期 / 失效条件（示例，非穷举）**：
    - 目标格已被占用（含领主或其它角色新造建筑）
    - 申请者当前金钱不足以支付购地价（及约定的其它费用）
    - 选址规则不再满足（邻域设施被拆、地形变化等）
  - 校验通过后：扣款并完成该格土地所有权转移，允许在该格开工建造
  - 若方案还包含向他人**购置占格**等步骤，见「组合建造方案与领主审批」；领主审批通过时须对**整单方案**重验，而非只验购地一格
- **开放问题**：见 [open-decisions.md](open-decisions.md) **B1**、**B3**、**X10**

### 组合建造方案与领主审批

- **规则**：当最优建造方案同时包含「向领主购地（空地格）」与「向他人购置占格」等步骤时，角色向领主发起**一条**待办审批，概括整单方案；领主同意时须校验**整单**仍有效且费用仍可支付，任一条件不满足则**整单失效**，不部分执行。
- **说明**：
  - 角色先比选多格 Footprint 与组合路径（示例：买下一座他人建筑 + 再占一块空地，总成本最低）
  - 审批详情须写清：申请者、目标建筑类型、各步占格（哪格购地、哪格购置谁的建筑等）及涉及费用概要
  - **同意时整单重验（示例，非穷举）**：
    - 购地格仍为可售空地且购地规则仍满足
    - 购置格上**目标建筑仍在**、卖方未变、该格**当日估值**买方仍**支付得起**
    - 申请者对**购地价 + 购置价 + 方案约定的其它支出**合计仍**支付得起**
    - 多格 Footprint 与邻域等选址规则仍满足
  - 校验全部通过后，按方案顺序执行各步（顺序待定）；任一步失败则整单不成交或回滚策略待定
  - 仅含购地、不含领主以外步骤的单格方案，仍适用本节整单重验逻辑（退化为只验购地相关条件）
- **开放问题**：见 [open-decisions.md](open-decisions.md) **B2**、**B3**

### 领主收回占格

- **规则**：领主若要收回某格上的土地，须向该格**建筑主人**按后者报价**买回建筑**；不得单方面无偿收回。
- **说明**：
  - 角色已向领主永久购得的土地，所有权在角色侧；领主不能重复售地或无偿夺地
  - 格上已有建筑时，领主收回须按**建筑回购**处理：卖方为建筑主人，买方为领主；回购定价机制尚未确定
  - 领主发起询价/购回；成交前须校验领主**支付得起**且交易仍有效（建筑仍在、所有者未变等）
  - 回购成交后土地/占格归属如何处理（归领主、清空等）尚未确定
- **开放问题**：见 [open-decisions.md](open-decisions.md) **S2**；买回后建筑处置、购回 UI（P2）

### 无空地则购置占格权

- **规则**：工作场所与住房均采用同一逻辑：找不到符合条件的空地时，改为向他人购置既有建筑所占格位。
- **说明**：
  - 购置对象是当前格上的建筑实例及其占格权，不是入住或使用原建筑功能
  - 住房与工作场所无不同的购置分支

### 购置即拆后自建

- **规则**：购置的含义是：付价取得占格权 → 拆掉原建筑 → 在同一格建造自己的目标建筑。
- **说明**：
  - 不存在「买下后继续当铁匠铺/继续当别人的茅舍用」的玩法路径
  - 卖方失去该格建筑；买方获得该格并在拆除后自建
- **开放问题**：见 [open-decisions.md](open-decisions.md) **X5**

### 购置询价：买方发起、比价选址

- **规则**：购置由买方发起；买方对多个候选格分别**询价**，选取报价最低者**直接决定**是否购买并完成交易。
- **说明**：
  - 候选格为通过买方目标建筑选址规则、且格上已有他人建筑的占格
  - 每格询价独立；格上须有可估值的建筑实例，否则该格不可询价
  - 买方在**支付得起**的候选格中，选取报价最低者；无任一格满足则购置失败
- **开放问题**：见 [open-decisions.md](open-decisions.md) **X6**

### 占格购置成交价

- **规则**：占格购置的**报价与成交价**均为该格建筑实例的当日**建筑估值**（[building-valuation-calculator.md](building-valuation-calculator.md)）；**无议价**。
- **说明**：
  - 买方询价 → 系统按估值计算器返回单一金额 → 买方**接受或放弃**；不存在还价、卖方保留价或反复出价
  - 卖方被动应答（返回估值即可），无需卖方 AI 参与定价决策
  - 成交时以询价时刻（或实现约定的重验时刻）的估值扣款；组合方案整单重验时须复算各购置格估值仍支付得起
  - 估值 v0 公式见 [building-valuation-calculator.md](building-valuation-calculator.md)；领主回购是否同机制见 [open-decisions.md](open-decisions.md) **S2**
