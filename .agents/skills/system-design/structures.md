# 建筑 / 选址

### 建筑

- **规则**：场内可建造实体统称**建筑**（示例：铁匠铺、酒馆、茅舍、奢侈宅邸）；占格、建造、购置见下文；**运营**（税收、床位租金、雇员、储备）见 [commerce.md](commerce.md)；**估值**见 [building-valuation-calculator.md](building-valuation-calculator.md)。
- **说明**：
  - 各类型在配置中区分**床位数**、**日税**、**雇员岗**、**上岗窗口**、**配置住房等级**等；**不再**分「商业 / 住房」两套经济模型
  - 具体类型列表与数值尚未全部定义

### 住房等级与服务等级

- **规则**：具备**配置住房等级**的建筑类型，现场按邻域覆盖计算**服务等级**；**实际住房等级** = `min(配置住房等级, 服务等级)`。
- **说明**：
  - **服务等级**：由**放置锚点格**周围建筑覆盖决定；等级阶梯要求邻域内存在指定类型建筑（示例：2 级须覆盖酒馆，3 级还须覆盖铁匠铺）
  - 实际住房等级约束**选址**（能否达到目标类型的有效居住品质）与 [needs.md](needs.md) **生活水平**；**不**用于占格购置估值（估值走建筑创值，见 [building-valuation-calculator.md](building-valuation-calculator.md)）
  - 生活水平须**先**出现【服务】诉求、**后**才解锁须高**服务等级**的升档住房，见 [needs.md](needs.md)「阶梯顺序：先【服务】、后高阶住房」
  - 邻域半径、等级阶梯与设施类型表按类型配置；邻域中心为 Footprint **放置锚点格**（最左格），**不**按门；奢侈住房示例见 [beautiful-corners/luxury-housing.md](beautiful-corners/luxury-housing.md)

### 占格与碰撞

- **规则**：建筑**占用的格子**与**碰撞格子**为同一集合：碰撞覆盖到哪一格，该格即被该建筑占用，占用格全部产生碰撞。类型配置**占格数**（横向连续格数）；**不**按门/入口配置或特殊处理占格。
- **说明**：
  - 配置示例：占格数 `2` → 连续 2 格均占用、均碰撞；单格建筑占格数 `1`
  - Footprint 即该连续占格；**放置锚点**为最左格（定位用，与门无关）；选址须一次性满足全部占格可用
  - **两栋建筑的占用格不可重叠**
  - 门的视觉位置若存在，不影响占用、碰撞、选址与购地判定
  - 占格上是空地还是他人建筑、是否须领主审批，见「占格与购地审批」
  - 比选多格方案、组合购地见「组合建造方案与领主审批」；示例 [beautiful-corners/multi-tile-workshop.md](beautiful-corners/multi-tile-workshop.md)
  - **已废止**：每栋有且仅有一个入口、脚下坐标=入口格、按入口左/右侧配占格；非入口格可重叠、仅入口格互斥

### 占格与购地审批

- **规则**：Footprint 内每一格：无建筑占用则为**空地格**，须向领主购地；已被他人建筑占用则须**购置该建筑实例**（整栋拆除，按其全部占格清场，即使本 Footprint 只交到其中部分格）。方案含空地格或须购置实例时走领主审批；购地价**仅计入空地格**。
- **说明**：
  - 土地为**刻意简化**模型（见「占地权属」）：**不**模拟真实土地产权；审批门槛为「是否有空地格须购地，或是否有他人建筑须购置」
  - 空地格：须向领主购地并走审批
  - 他人占用格：购置对应建筑实例（**每实例一次**成交），不向领主购该实例已占的格
  - 拆除后其全部占格腾空；目标 Footprint **未覆盖**的腾空格归领主空地，买方不获得那些格的占用权
  - 组合待办详情、购地价合计与异步检查：购地只针对空地格；购置按相交的他人建筑实例计（不按格拆开同一实例）
  - **已废止**：「被覆盖 / 未被覆盖」（邻楼外延占格重叠免购地；全部被覆盖时跳过审批、不入待办）

### 地形约束

- **规则**：选址时**仅**校验建筑 **Footprint 占格**各自下方的地形；Footprint **每一格**须为**陆地**方可建造。
- **说明**：
  - 地形仅分陆地与水；**不按建筑类型维护独立地形规则表**，默认全场建筑均须落在陆地上
  - **邻域**仅用于**服务等级**等业务判定（见「住房等级与服务等级」），不用于地形校验
  - 多格建筑须全部占格均为陆地；任一占格为水格则该 Footprint 不可选

### 多格占地建筑

- **规则**：Footprint 占多格的建筑类型，选址与权属安排须一次性覆盖该类型配置的全部占格（见「占格与碰撞」）。
- **说明**：
  - 占格可混合「须向领主购地的空地」与「须向他人购置并拆除的已占格」
  - 角色可为同一栋多格建筑规划**组合方案**（比价后选取总成本最优者），见「组合建造方案与领主审批」
  - 与代码现状的差异：当前为一格一建筑实例，多格占地待实现

### 建筑主人确立

- **规则**：**建筑主人**在**建造责任方放置地基**的瞬间确立，归属该次建造的**责任方角色**；须晚于占地与权属安排（购地审批通过、购置拆除等前置结算完成）。
- **说明**：
  - 地基前仅有评估、待办、比选；**无**建筑主人
  - 地基至竣工为「建造中」工地，主人已确立；床位、营业、雇员岗等建筑功能按类型在**竣工后**生效，见「建造施工流程」
  - 购置成交时卖方失去该建筑实例及主人身份；买方在**同一 Footprint 放置地基**后成为新建筑主人

### 占地权属

- **规则**：土地**刻意简化**，不与现实产权一一对应；**不**按格登记土地产权或购地台账。建筑占用格**互斥**（见「占格与碰撞」）；**空地格**须向领主购地并走审批，**他人占用格**按「占格与购地审批」购置拆除。
- **说明**：
  - 组合方案中购地格与购置实例仅用于审批与结算步骤区分，落成后**不**保留按格权属记录
  - 购地付费取得**建造占用权**（非永久土地所有权）；占格清场后土地归领主，见「向领主购地与领主审批」「占格清场」
  - **已废止**：允许 Footprint 部分重叠；被覆盖格不购地、不审批

### 建造施工流程

- **规则**：完成占地与权属安排后，建造须依次经历：**放置地基 → 填充材料至满 → 雇佣建筑工施工至竣工**；竣工建筑只能由建筑工完成最后施工阶段。**每名角色**作为建造责任方，**同一时间仅允许一处**「建造中」工地（含待审批、地基/填料/待施工）；须等当前工地**竣工**或**取消**后方可另起新建造。
- **说明**：
  - 前置步骤含向领主购地/审批、购置他人建筑并拆除、组合方案整单执行等，见上文各节
  - 各建筑类型的**材料清单与施工耗时**见「建筑材料与施工耗时」；资源标签见 [economy.md](economy.md)「资源与标签」
  - 材料填满后触发「雇佣建筑工」：全场选人、转职上岗；雇工**日薪上限**绑责任方**个体创值**（非工地预算），低创值者可**自雇**兜底（见 [characters.md](characters.md)「雇佣建筑工」）；雇不到人时**隔一段时间重试**；**竣工瞬间**解雇建筑工
  - 受雇**建筑工**同一时刻**仅服务一处**工地，不并行施工多栋建筑
  - **竣工瞬间**记录该实例**竣工时刻**，供 [building-valuation-calculator.md](building-valuation-calculator.md)「竣工保护加成」起算
  - 与代码现状的差异：当前建造为放置即完成，无地基/材料/雇工阶段

### 工地异常（欠薪与死亡）

- **规则**：**欠薪**时，或**建造责任方**、该工地**相关雇员**（含建筑工）**死亡**时：**立即强制结算**未结清薪酬（见 [characters.md](characters.md)「雇员薪酬结算」）、**解除**相关雇佣并走「雇佣职业离职」；对该**建造中工地**执行**占格清场**（取消建造）。**死亡机制首版暂不实现**，上款为启用死亡时的规则。
- **说明**：
  - 欠薪判定与结算时刻见 [characters.md](characters.md)「雇员薪酬结算」
  - 清场后不退还已填材料、购地价；死亡与欠薪后果一致
  - 死亡时角色货币/物资归属等待 [economy.md](economy.md)「角色离场与死亡」另行定义
  - **规划**（暂不实现）：中期**犯罪**（枷台等）、长期**农奴**等机制可能改变工地与雇佣边界

### 建筑材料与施工耗时

- **规则**：每种建筑类型在配置中声明**填料阶段**所需的具体资源及数量，以及**施工阶段**耗时；填料须按清单逐项缴满后方可雇建筑工。
- **说明**：
  - 材料条目为**具体资源品种**（如简易建材、高级建材），非标签；品种自身可带标签（见 [economy.md](economy.md)）
  - 配置示例（非平衡定案）：`简易建材 × 100`、`高级建材 × 50`、**施工耗时** `20` 游戏小时
  - 各类型具体数值、填料是否耗时分步缴付等待内容配置；结构为「清单 + 施工耗时」

### 建造可负担判定

- **规则**：角色评估是否发起建造（**住房**或**商业**）时，须同时满足：(1) **支付得起整单建造费用**（购地价、购置价、填料材料等，按当日比选方案合计）；(2) **支付得起首个游戏月**（**7 个游戏日**）的**运营支出**（按目标类型**满员满效率**估算，见 [commerce.md](commerce.md)「运营支出与运营储备」）。
- **说明**：
  - **住房建造触发**（[needs.md](needs.md)）、**商业建筑投资**（见下）共用本判定
  - 日更评估**不因**领主待办在队而视为不可负担（同 needs.md「住房建造触发」）
  - 纯住宅无生产、无雇员岗时，运营支出仅含日税

### 商业建筑投资

- **规则**：每名角色**每个游戏月**（7 游戏日）尝试一次**商业投资**：从配置中全部**可能盈利**的商业建筑类型里**随机抽选**一种；若该角色**无**进行中工地且通过「建造可负担判定」，则按本章**完整**选址与比选流程发起建造。
- **说明**：
  - **盈利判定**：场内已有**同类型**竣工建筑 → 取该类 **创值·最近 1 游戏年**算术平均；**无同类** → 用该类型**创值预测**（满效率预期售品收入 + 满床床位租金，见 [economy.md](economy.md)「创值预测」）
  - 首版「可能盈利」商业类型配置先含**酒馆**；铁匠铺、澡堂等后续扩展
  - 与住房建造共用「每名角色仅一处建造中工地」，见「建造施工流程」
  - 真正结算须待领主审批通过（含购地时），流程同「领主审批流程」

### 建造选址：先空地

- **规则**：角色需要某类建筑时，先在地图上寻找满足该类型条件的选址；Footprint 中的**空地格**须向领主**支付购地价**取得建造许可并经领主同意（见「占格与购地审批」）。住房建造动机见 [needs.md](needs.md)「住房建造触发」；商业建造动机见「商业建筑投资」。
- **说明**：
  - 「空地」指**陆地**格、无建筑占用、无**环境物**占用，且通过该建筑类型选址规则的位置；地形校验见「地形约束」
  - 具备配置住房等级的类型须满足目标**服务等级**要求（邻域覆盖，见「住房等级与服务等级」）
  - 与代码现状的差异：当前仅检查格空，地形/环境物/服务等级/多格碰撞等规则待实现
  - **向领主购地仅适用于空地格**；向他人购置建筑（拆后自建）不走领主售地，见「无空地则购置占格权」
  - **AI 选址约束**：角色 AI **不得**选择须拆除**领主（玩家）为建筑主人**的建筑方能落地的方案；可购置并拆除场内其他角色建筑

### 向领主购地与领主审批

- **规则**：目标 Footprint 含**空地格**或须**购置**他人建筑时，须向领主（玩家）发起审批；其中空地格在审批通过后按格**购地价**完成付费（申请者 → 领主，见 [economy.md](economy.md)）。
- **说明**：
  - 审批范围与购地价计费格见「占格与购地审批」；他人占用格走购置，不收购地价
  - **购地价按格定价**（仅计空地格）；**暂定**全场统一单价，后续可扩展为**分区域**不同价格（见「购地价」）
  - **设定上**双方可有土地契约；**游戏中简化**：不实现「地契」道具、库存或独立契约界面，仅以待办审批 + 货币交易表示购地
  - 购地**非**永久土地所有权：付费取得**建造占用权**；占格**清场**后土地**归领主**，见「占格清场」
  - 申请进入界面**待办队列**（入口见「待办队列 UI」）；审批交互见「领主审批流程」
  - 若方案还包含向他人**购置建筑**等步骤，见「组合建造方案与领主审批」

### 待办队列 UI

- **规则**：领主（玩家）通过界面**左上角感叹号按钮**打开**待办事件队列**；点选队列项进入审批详情，按「领主审批流程」处理。
- **说明**：
  - 队列收纳含**空地购地**或**购置他人建筑**的方案待办
  - 无待办时可隐藏按钮或置灰（实现自定）
  - 异步检查不通过时的反馈文案 v0 先用 **placeholder**，后续再调

### 领主审批流程

- **规则**：领主（玩家）处理购地或含购地的**组合方案**待办时，按下列顺序执行：
  1. **打开审批详情** → 执行一次**异步检查**；不通过则提示**请求已过期**并结束
  2. 领主点**拒绝** → 结束，不结算
  3. 领主点**同意** → 再执行一次**异步检查**；不通过则提示**请求已过期**并结束
  4. **结算交易**（整单原子完成）
- **说明**：
  - **异步检查**（步骤 1、3 相同）：验证申请者**仍有购买/建造意愿**（方案仍成立，示例：空地格仍空、须购置的建筑实例仍在、选址与占格碰撞判定仍满足）且**仍支付得起**整单费用（购地价仅计空地格）
  - 单格仅购地与多步组合方案共用本流程；组合方案在步骤 4 **一次性结算**全部交易（购地、购置等），无分步执行与中途回滚
  - 待办排队期间**不锁定**涉及格子；抢建、占格等冲突由打开/同意时的**异步检查**判定，不通过则「请求已过期」
  - 详情文案示例：「{角色}希望在{位置}建造{建筑类型}，须向领主购地（列明空地格与须购置的建筑）」

### 购地价

- **规则**：向领主购地按**格**收取购地价，且**仅**对空地格计费；多格方案中各空地格分别计价后合计支付。
- **说明**：
  - 他人占用格不收购地价、不进入购地结算（走购置）
  - **暂定**全场各格**统一单价**；实现上仍按格存储/查询，便于日后按**区域**区分价格
  - 购地价独立于 [building-valuation-calculator.md](building-valuation-calculator.md) 建筑估值

### 组合建造方案与领主审批

- **规则**：当最优建造方案含**空地格**或须**购置**他人建筑时，角色向领主发起**一条**待办审批，概括整单方案（空地格 + 须购置的建筑实例）；领主按「领主审批流程」处理，通过后**一次性结算**整单。
- **说明**：
  - 角色先比选多格 Footprint 与组合路径（示例：买下一栋他人建筑 + 再占一块空地，总成本最低）；比选须遵守「AI 选址约束」
  - 审批详情须写清：申请者、目标建筑类型、各空地格（购地）与须购置的建筑实例（谁的、估值）及费用概要
  - 异步检查须覆盖整单：空地格仍可售、须购置的建筑实例仍在且估值仍可成交、合计费用仍支付得起、Footprint 碰撞与邻域规则仍满足
  - 相交的他人建筑按其**整栋估值**计入成本；拆除后未纳入本 Footprint 的腾空格归领主
  - 示例 walkthrough：[beautiful-corners/multi-tile-workshop.md](beautiful-corners/multi-tile-workshop.md)

### 占格清场

- **规则**：下列情形占格**建筑消失**、土地**归领主**、格变为**彻底空地**：**弃房**（换房舍弃旧住房、误建舍弃新住房，见 [needs.md](needs.md)「换房与弃房」）；**工地取消**（含欠薪、责任方或雇员死亡，见「工地异常（欠薪与死亡）」）；**交不起日税**（税务官收款失败后拆毁，见 [commerce.md](commerce.md)「日税与税务官」）。
- **说明**：
  - **不退**购地价、**不**回购、**不**回收材料；领主**不**向角色支付补偿
  - 清场后该格视为领主空地，可再次售地或留空
  - **购置后拆除**（见「购置即拆后自建」）仅为施工步骤；拆除实例的占格中，仍属当前**建造中工地** Footprint 的**不**单独清场；未纳入该 Footprint 的腾空格归领主；方案取消时对该 Footprint 全部占格清场
  - **已废止**：原「领主收回占格」（领主按估值回购建筑）机制

### 无空地则购置占格权

- **规则**：找不到整段符合条件的空地 Footprint 时，改为纳入他人建筑所占格（购置实例、拆后自建，**不分**类型）。
- **说明**：
  - 购置对象是建筑实例及其全部占用格，不是入住或使用原建筑功能

### 购置即拆后自建

- **规则**：购置的含义是：付价取得该建筑实例的占格权 → 拆掉原建筑（其全部占用格腾空） → 在目标 Footprint 上建造自己的目标建筑。
- **说明**：
  - 不存在「买下后继续当铁匠铺/继续当别人的茅舍用」的玩法路径
  - 卖方失去该建筑；买方在拆除后于目标 Footprint 自建
  - 拆毁规则见「建筑拆毁」

### 建筑拆毁

- **规则**：建筑**拆毁瞬间**，该实例账本内**全部货币与物资**转入**建筑主人**角色物品栏，随后建筑实例消失；拆毁本身**不消耗**额外物料或劳动。
- **说明**：
  - 适用于购置后拆除、交不起税拆毁、弃房等场景
  - **工地取消**（占格清场）时**已填入工地的材料不退还**，见「占格清场」「工地异常（欠薪与死亡）」
  - 后续若引入拆毁成本或回收机制再单独立项

### 购置询价：买方发起、比价选址

- **规则**：购置由买方发起；买方对多个候选 **Footprint 落点**分别估算整单费用（空地购地价 + 相交建筑实例估值），选取最低者**直接决定**是否购买并完成交易。
- **说明**：
  - **候选落点枚举**：扫描目标类型全部合法 **Footprint 落点**；落点与他人建筑占用格相交则计入须购置实例（每实例一次）；**排除**建筑主人为领主（玩家）的实例，见「AI 选址约束」
  - 每实例询价独立；须有可估值的建筑实例，否则该落点无法完成购置询价
  - 买方在**支付得起**的候选落点中，选取整单报价最低者；无任一落点满足则购置失败

### 占格建筑交易成交价

- **规则**：占格**购置**的**报价与成交价**均为该**建筑实例**的当日**建筑估值**（[building-valuation-calculator.md](building-valuation-calculator.md)）；**无议价**；成交价自**买方角色**划入**卖方建筑主人**角色物品栏（不经建筑账本）。
- **说明**：
  - 买方（角色）询价 → 系统按估值计算器返回单一金额 → 买方**接受或放弃**；不存在还价、卖方保留价或反复出价
  - 卖方被动应答（返回估值即可），无需卖方 AI 参与定价决策
  - 成交后买方拆毁原建筑，拆毁瞬间原建筑剩余资源按「建筑拆毁」归**原主人**（卖方）
  - 成交时以询价时刻（或实现约定的重验时刻）的估值扣款；组合方案整单重验时须复算各购置**实例**估值仍支付得起
  - 估值见 [building-valuation-calculator.md](building-valuation-calculator.md)（创值 + 类型保底 + 竣工保护加成）
