# 建筑 / 选址

## 已定决策

### 建筑分类

- **状态**：已定
- **规则**：建筑分「工作场所」与「住房」两类。
- **说明**：
  - 工作场所示例：铁匠铺
  - 住房示例：茅舍及更高级住宅
  - 具体类型列表与配置尚未定义

### 多格占地建筑

- **状态**：已定
- **规则**：部分建筑类型占**多个连续（或按配置相邻）格子**；选址与占格须一次性满足该类型对全部占格的要求。
- **说明**：
  - 占格可混合「须向领主购地的空地」与「须向他人购置并拆除的已占格」
  - 角色可为同一栋多格建筑规划**组合方案**（比价后选取总成本最优者），见「组合建造方案与领主审批」
  - 与代码现状的差异：当前为一格一建筑实例，多格占地待实现
- **开放问题**：
  - 多格 Footprint 形状（直线 N 格、其它模板）？
  - 组合方案的执行顺序（先购地 / 先购置 / 先拆后建）？

### 建造选址：先空地

- **状态**：已定
- **规则**：角色需要某类建筑时，先在地图上寻找满足该类型条件的空地；条件满足后须向领主**购得该格土地所有权**（永久买断）并经领主同意，方可在该格建造。
- **说明**：
  - 「空地」指可占格且通过该建筑类型选址规则的位置（与代码现状的差异：当前仅检查格空，邻域/地形等规则待实现）
  - 高级住房等类型可要求周边存在指定设施（邻域规则按类型配置）
  - **向领主购地仅适用于空地路径**；向他人购置占格（拆后自建）不走领主售地，见「无空地则购置占格权」
- **开放问题**：
  - 空地是否排除环境物占格（橡树、灌木、旌旗等）？
  - 各建筑类型的邻域/地形规则表？

### 向领主购地与领主审批

- **状态**：已定
- **规则**：角色在空地建造前，须向领主（玩家）申请**购买该格土地所有权**；领主同意且申请仍有效时，按领主设定的**购地价**完成永久买断（申请者 → 领主，见 [economy.md](economy.md)），随后可在该格建造。
- **说明**：
  - **设定上**双方可有土地契约；**游戏中简化**：不实现「地契」道具、库存或独立契约界面，仅以待办审批 + 货币交易表示购地
  - 购地为**永久买断**，非按次或临时租用；该格土地所有权归购买者（建筑产权另计，见「领主收回占格」）
  - 申请进入界面**待办队列**：队列中插入一项可点按钮
  - 点开展开详情界面，说明例如：「{角色}希望在{位置}建造{建筑类型}，须向领主购地」
  - **拒绝**：不成交、不转移土地所有权，该次申请结束（角色后续行为待定）
  - **同意**：执行前再次验证，防止申请**过期**；校验失败则不成交（等同拒绝或需提示原因，实现待定）
  - **过期 / 失效条件（示例，非穷举）**：
    - 目标格已被占用（含领主或其它角色新造建筑）
    - 申请者当前金钱不足以支付购地价（及约定的其它费用）
    - 选址规则不再满足（邻域设施被拆、地形变化等）
  - 校验通过后：扣款并完成该格土地所有权转移，允许在该格开工建造
  - 若方案还包含向他人**购置占格**等步骤，见「组合建造方案与领主审批」；领主审批通过时须对**整单方案**重验，而非只验购地一格
- **开放问题**：
  - 待办队列所属 UI 节点/场景？
  - 同意时校验失败给领主/角色的反馈文案？
  - 申请排队期间是否锁定该格（防抢建）？
  - 购地价为全局一口价还是按格/按类型可区分？

### 组合建造方案与领主审批

- **状态**：已定
- **规则**：当最优建造方案同时包含「向领主购地（空地格）」与「向他人购置占格」等步骤时，角色向领主发起**一条**待办审批，概括整单方案；领主同意时须校验**整单**仍有效且费用仍可支付，任一条件不满足则**整单失效**，不部分执行。
- **说明**：
  - 角色先比选多格 Footprint 与组合路径（示例：买下一座他人建筑 + 再占一块空地，总成本最低）
  - 审批详情须写清：申请者、目标建筑类型、各步占格（哪格购地、哪格购置谁的建筑等）及涉及费用概要
  - **同意时整单重验（示例，非穷举）**：
    - 购地格仍为可售空地且购地规则仍满足
    - 购置格上**目标建筑仍在**、卖方未变、该格报价仍可成交（出售权重 == 0 有解）
    - 申请者对**购地价 + 购置价 + 方案约定的其它支出**合计仍**支付得起**
    - 多格 Footprint 与邻域等选址规则仍满足
  - 校验全部通过后，按方案顺序执行各步（顺序待定）；任一步失败则整单不成交或回滚策略待定
  - 仅含购地、不含领主以外步骤的单格方案，仍适用本节整单重验逻辑（退化为只验购地相关条件）
- **开放问题**：
  - 整单执行中原子步骤失败是否回滚已完成的购地/付款？
  - 审批排队期间是否锁定方案涉及的全部格子？

### 领主收回占格

- **状态**：已定
- **规则**：领主若要收回某格上的土地，须向该格**建筑主人**按后者报价**买回建筑**；不得单方面无偿收回。
- **说明**：
  - 角色已向领主永久购得的土地，所有权在角色侧；领主不能重复售地或无偿夺地
  - 格上已有建筑时，领主收回须按**建筑回购**处理：卖方为建筑主人，买方为领主；成交价由「出售权重计算器」反推**总权重 == 0**（见「出售权重计算器」）
  - 领主发起询价/购回；成交前须校验领主**支付得起**且交易仍有效（建筑仍在、所有者未变等）
  - 回购成交后土地/占格归属如何处理（归领主、清空等）尚未确定
- **开放问题**：
  - 买回后建筑保留、拆除或归领主处置？
  - 购回是否也走待办队列与同意时重验 UI？

### 无空地则购置占格权

- **状态**：已定
- **规则**：工作场所与住房均采用同一逻辑：找不到符合条件的空地时，改为向他人购置既有建筑所占格位。
- **说明**：
  - 购置对象是当前格上的建筑实例及其占格权，不是入住或使用原建筑功能
  - 住房与工作场所无不同的购置分支

### 购置即拆后自建

- **状态**：已定
- **规则**：购置的含义是：付价取得占格权 → 拆掉原建筑 → 在同一格建造自己的目标建筑。
- **说明**：
  - 不存在「买下后继续当铁匠铺/继续当别人的茅舍用」的玩法路径
  - 卖方失去该格建筑；买方获得该格并在拆除后自建
- **开放问题**：
  - 拆毁是否消耗物料/劳动时间？

### 购置询价：买方发起、比价选址

- **状态**：已定
- **规则**：购置由买方发起；买方对多个候选格分别向各格卖方询价，选取成交价最低者完成购置。
- **说明**：
  - 候选格为通过买方目标建筑选址规则、且格上已有他人建筑的占格
  - 每格询价独立，得到该格对应的最终成交价（见「出售权重计算器」）
  - 买方在**可成交且自身支付得起**的候选格中，选取成交价最低者；无任一格满足则购置失败
- **开放问题**：
  - 候选格枚举范围（全图 / 半径 / 数量上限）？

### 出售权重计算器

- **状态**：已定
- **规则**：占格购置价由出售权重计算器得出；先算不含金钱的对价权重，再反推使**总权重 == 0** 的金额，该金额即为该笔交易的最终成交价。
- **说明**：
  - 与 [characters.md](characters.md) 中转职权重计算器同构：非金钱因素汇总后，金钱作为补偿项参与总权重
  - 与佣金的差异：佣金为使总权重 **> 0** 的最低金额；出售为使总权重 **== 0** 的金额（卖方在此价上无保留、无额外索价）
  - 因素方向与列表尚未定义（示例：仍在使用、重置成本、区位稀缺、体面、急用钱等）
  - 占格权交易不适用 [economy.md](economy.md) 的同质「流通商品」日价公式；物料重置成本折钱时可引用当日商品市价
  - 若不存在有限金额能使总权重 == 0（例如非金钱权重过强且金钱项无法拉平），视为该格不可成交
- **开放问题**：
  - 非金钱因素列表与权重公式？
  - 金钱项与总权重的具体函数形式（线性、分段）？

## 设计示例：最美角落

> 下列数值与建筑名为**叙事用示例配置**，非全局平衡定案；用于串联已定流程。

**背景**：某角色原住简陋住房，积蓄后欲改建/迁入**奢侈住房**。该类型选址规则（示例）：以目标格为中心 **15 格**内须同时存在**酒馆**与**铁匠铺**（邻域设施由地图现状判定，非买方自带）。

**稀缺**：全图仅 **2 格**满足上述奢侈住房选址；两格皆已被占——分别为**木匠铺**、**澡堂**（工作场所）。无合格空地 → 走「购置占格权」分支。

**询价与成交**（买方发起）：

1. 对两格各向当前占格所有者询价 → 出售权重计算器给出各格最终价（总权重 == 0 的金额）。
2. 澡堂格报价低于木匠铺格，且买方**支付得起**澡堂价。
3. 买方在可成交且支付得起的候选格中取**最低价** → 选中澡堂格。
4. 付价 → **拆掉澡堂** → 在同一格**自建奢侈住房**。

**要点**：奢侈条件由**周边已有**酒馆/铁匠铺满足；买方买的是「稀缺区位上的占格权」，不是澡堂或木匠铺的功能。两格同享同一套周边设施时，比价发生在**不同卖方、不同实例**的拆买价之间。

## 设计示例：多格铺位

> 叙事用示例；Footprint 格数、建筑名称为示意。

**目标**：某角色要建一座**占地跨多格**的建筑（示例：长条作坊占 **3 格**）。比选 Footprint 后，最省方案为：**1 格**上已有他人建筑须**购置拆毁**，**1 格**为空地须**向领主购地**，余下占格由已持有或购地/购置后凑齐（本例中即「买 1 座别人的 + 买 1 块空地」）。

**审批**：因含空地购地，向领主发起**一条**待办，说明例如：「{角色}拟在{格 A、格 B…}建造{类型}：格 B 须购地，格 A 须向{卖方}购置{现建筑}后拆除」。

**领主同意时**：

- 若格 A 上**目标建筑已不在**（已拆、已售、已毁），或卖方/报价已变导致不可成交 → **整单失效**
- 若格 B 已被占或购地规则不满足 → **整单失效**
- 若角色对购地价 + 购置价等**合计支付不起** → **整单失效**
- 以上均通过 → 执行整单（购地、付价购置并拆除、在多格 Footprint 上开工建造；步骤顺序待定）

**要点**：购置不占领主审批的格**不单独**再向领主开第二条购地外的审批，但**纳入**同一整单；领主点同意时承担的是「这单组合方案现在还能不能做成」的校验，而非只批准空地那一格。
