# 建筑 / 选址

### 建筑分类

- **规则**：建筑分「工作场所」（商业建筑）与「住房」两类；估值模型分岔见 [building-valuation-calculator.md](building-valuation-calculator.md)；商业建筑经营见 [commerce.md](commerce.md)。
- **说明**：
  - 工作场所示例：铁匠铺、酒馆、澡堂
  - 住房示例：茅舍及更高级住宅；每类住房配置**住房等级**
  - 具体类型列表与配置尚未定义

### 住房等级与服务等级

- **规则**：住房类型配置**住房等级**；现场按邻域商业覆盖计算**服务等级**；**实际住房等级** = `min(配置住房等级, 服务等级)`。
- **说明**：
  - **服务等级**：由目标格周围商业建筑覆盖决定；等级阶梯要求邻域内存在指定类型商业建筑（示例：2 级须覆盖酒馆，3 级还须覆盖铁匠铺）
  - 实际住房等级同时约束**选址**（能否达到目标住房类型的有效等级）与**估值**（见 [building-valuation-calculator.md](building-valuation-calculator.md)「住房估值」）
  - 邻域半径、等级阶梯与设施类型表按类型配置；奢侈住房示例见 [beautiful-corners/luxury-housing.md](beautiful-corners/luxury-housing.md)

### Footprint 与入口

- **规则**：每栋建筑**有且仅有**一个**入口**，位于**某一格的中心**；建筑的**脚下坐标**（放置/定位锚点）即**入口所在格**的坐标。建筑类型配置入口格**左侧**与**右侧**各占格数，与入口格本身共同构成 Footprint。
- **说明**：
  - 配置示例：`左侧 0`、`右侧 1` → 入口格 + 右侧 1 格，共占 **2 格**；单格建筑为 `左侧 0`、`右侧 0`
  - Footprint 为入口格及其左右连续占格（横向一条）；选址时须一次性满足全部占格可用且**入口格**未被占用为其他建筑入口
  - **建筑占格可以重叠**（非入口格可与另一建筑占格重合）；**任一格子不得与另一建筑的入口格重叠**
  - 占格是否被既有建筑「覆盖」、是否须领主审批，见「占格覆盖与购地审批」
  - 比选多格方案、组合购地见「组合建造方案与领主审批」；示例 [beautiful-corners/multi-tile-workshop.md](beautiful-corners/multi-tile-workshop.md)

### 占格覆盖与购地审批

- **规则**：Footprint 内一格若已落入场内某既有建筑 Footprint 的占格范围（含非入口格重叠），且该格上**无**须拆除的他人建筑实例，则称该格**被覆盖**；否则称**未被覆盖**。目标 Footprint **全部被覆盖**时**跳过**领主审批；**任一格未被覆盖**时须走领主审批，且审批与购地价**仅计入未被覆盖的格**（其中须向领主购地的空地格收购地价，须购置的格纳入组合方案中的购置步骤）。
- **说明**：
  - **被覆盖**：仅因邻接建筑外延占格而重叠，不涉及拆毁、不向领主购地
  - **未被覆盖**：含真空地、格上仍有他人建筑实例（须购置拆毁）等；**任一格未被覆盖**即须领主审批
  - **全部被覆盖**时无购地、无购置、无待办，建造责任方在权属满足后直接走施工流程
  - 组合待办详情、购地价合计与异步检查：购地只针对**未被覆盖**的空地格；购置只针对**未被覆盖**且格上有他人建筑的格（**被覆盖**格不出现在待办计费中）

### 地形约束

- **规则**：选址时**仅**校验建筑 **Footprint 占格**各自下方的地形；Footprint **每一格**须为**陆地**方可建造。
- **说明**：
  - 地形仅分陆地与水；**不按建筑类型维护独立地形规则表**，默认全场建筑均须落在陆地上
  - **邻域**仅用于住房**服务等级**等业务判定（见「住房等级与服务等级」），不用于地形校验
  - 多格建筑须全部占格均为陆地；任一占格为水格则该 Footprint 不可选

### 多格占地建筑

- **规则**：Footprint 占多格的建筑类型，选址与权属安排须一次性覆盖该类型配置的全部占格（见「Footprint 与入口」）。
- **说明**：
  - 占格可混合「须向领主购地的空地」与「须向他人购置并拆除的已占格」
  - 角色可为同一栋多格建筑规划**组合方案**（比价后选取总成本最优者），见「组合建造方案与领主审批」
  - 与代码现状的差异：当前为一格一建筑实例，多格占地待实现

### 建造施工流程

- **规则**：完成占地与权属安排后，建造须依次经历：**放置地基 → 填充材料至满 → 雇佣建筑工施工至竣工**；竣工建筑只能由建筑工完成最后施工阶段。
- **说明**：
  - 前置步骤含向领主购地/审批、购置他人建筑并拆除、组合方案整单执行等，见上文各节
  - 各建筑类型的**材料清单与施工耗时**见「建筑材料与施工耗时」；资源标签见 [economy.md](economy.md)「资源与标签」
  - 材料填满后触发「雇佣建筑工」：全场选人、转职上岗；**竣工瞬间**解雇建筑工，见 [characters.md](characters.md)
  - **每名角色作为建造责任方**，同一时间仅允许**一处**「建造中」工地（含地基/填料/待施工阶段）；第二处须等当前工地竣工或取消
  - 与代码现状的差异：当前建造为放置即完成，无地基/材料/雇工阶段

### 工地异常（欠薪与死亡）

- **规则**：**欠薪**时**立即解除**相关雇佣关系（含建筑工等），走「雇佣职业离职」流程；**建造责任方或雇员死亡**时工地如何处理**暂不处理**。
- **说明**：
  - 欠薪判定与结算时刻见 [characters.md](characters.md)「雇员薪酬结算」
  - 工地在雇工被解雇后的进度保留/停工等待后续设计；责任方死亡同理暂不定义
  - **规划**（暂不实现）：中期**犯罪**（枷台等）、长期**农奴**等机制可能改变工地与雇佣边界

### 建筑材料与施工耗时

- **规则**：每种建筑类型在配置中声明**填料阶段**所需的具体资源及数量，以及**施工阶段**耗时；填料须按清单逐项缴满后方可雇建筑工。
- **说明**：
  - 材料条目为**具体资源品种**（如简易建材、高级建材），非标签；品种自身可带标签（见 [economy.md](economy.md)）
  - 配置示例（非平衡定案）：`简易建材 × 100`、`高级建材 × 50`、**施工耗时** `20` 游戏小时
  - 各类型具体数值、填料是否耗时分步缴付等待内容配置；结构为「清单 + 施工耗时」

### 建造选址：先空地

- **规则**：角色需要某类建筑时，先在地图上寻找满足该类型条件的选址；其中**未被覆盖**且为真空的格，须向领主**购得该格土地所有权**（永久买断）并经领主同意（见「占格覆盖与购地审批」）；**被覆盖**的占格不占审批、不收购地价。
- **说明**：
  - 「空地」指**陆地**格、无玩家建筑占格、无**环境物**占格、且**未被覆盖**（见「占格覆盖与购地审批」），且通过该建筑类型选址规则的位置；地形校验见「地形约束」
  - 住房须满足目标类型的**服务等级**要求（邻域商业覆盖，见「住房等级与服务等级」）
  - 与代码现状的差异：当前仅检查格空，地形/环境物/服务等级/占格覆盖等规则待实现
  - **向领主购地仅适用于未被覆盖的空地格**；向他人购置占格（拆后自建）不走领主售地，见「无空地则购置占格权」
  - **AI 选址约束**：角色 AI **不得**选择须拆除**领主（玩家）为建筑主人**的建筑方能落地的方案；可购置并拆除场内其他角色建筑

### 向领主购地与领主审批

- **规则**：目标 Footprint 中**任一格未被覆盖**时，须向领主（玩家）发起审批；其中**未被覆盖**且须购地的空地格，审批通过后按格**购地价**完成永久买断（申请者 → 领主，见 [economy.md](economy.md)）。**全部被覆盖**时**不**进入待办、不向领主购地。
- **说明**：
  - 审批范围与购地价计费格见「占格覆盖与购地审批」；**被覆盖**格不参与
  - **购地价按格定价**（仅计须购地的未被覆盖空地格）；**暂定**全场统一单价，后续可扩展为**分区域**不同价格（见「购地价」）
  - **设定上**双方可有土地契约；**游戏中简化**：不实现「地契」道具、库存或独立契约界面，仅以待办审批 + 货币交易表示购地
  - 购地为**永久买断**，非按次或临时租用；该格土地所有权归购买者（建筑产权另计，见「领主收回占格」）
  - 申请进入界面**待办队列**（入口见「待办队列 UI」）；审批交互见「领主审批流程」
  - 若方案还包含向他人**购置占格**等步骤，见「组合建造方案与领主审批」

### 待办队列 UI

- **规则**：领主（玩家）通过界面**左上角感叹号按钮**打开**待办事件队列**；点选队列项进入审批详情，按「领主审批流程」处理。
- **说明**：
  - 队列收纳**任一格未被覆盖**的购地或组合方案待办；Footprint **全部被覆盖**的方案不入队
  - 无待办时可隐藏按钮或置灰（实现自定）
  - 异步检查不通过时的反馈文案 v0 先用 **placeholder**，后续再调

### 领主审批流程

- **规则**：领主（玩家）处理购地或含购地的**组合方案**待办时，按下列顺序执行：
  1. **打开审批详情** → 执行一次**异步检查**；不通过则提示**请求已过期**并结束
  2. 领主点**拒绝** → 结束，不结算
  3. 领主点**同意** → 再执行一次**异步检查**；不通过则提示**请求已过期**并结束
  4. **结算交易**（整单原子完成）
- **说明**：
  - **异步检查**（步骤 1、3 相同）：验证申请者**仍有购买/建造意愿**（方案仍成立，示例：**未被覆盖**的购地格仍空、**未被覆盖**的购置格建筑仍在、选址与占格覆盖判定仍满足）且**仍支付得起**整单费用（购地价仅计须购地的未被覆盖格）
  - 单格仅购地与多步组合方案共用本流程；组合方案在步骤 4 **一次性结算**全部交易（购地、购置等），无分步执行与中途回滚
  - 待办排队期间**不锁定**涉及格子；抢建、占格等冲突由打开/同意时的**异步检查**判定，不通过则「请求已过期」
  - 详情文案示例：「{角色}希望在{位置}建造{建筑类型}，须向领主购地（列明**未被覆盖**的购地格与购置格）」

### 购地价

- **规则**：向领主购地按**格**收取购地价，且**仅**对**未被覆盖**且须购地的空地格计费；多格方案中各此类购地格分别计价后合计支付。
- **说明**：
  - **被覆盖**格不收购地价、不进入购地结算
  - **暂定**全场各格**统一单价**；实现上仍按格存储/查询，便于日后按**区域**区分价格
  - 购地价独立于 [building-valuation-calculator.md](building-valuation-calculator.md) 建筑估值

### 组合建造方案与领主审批

- **规则**：当最优建造方案中**任一格未被覆盖**时，角色向领主发起**一条**待办审批，概括整单方案（**未被覆盖**的购地格 + **未被覆盖**的购置格）；领主按「领主审批流程」处理，通过后**一次性结算**整单。**全部被覆盖**时不发起待办。
- **说明**：
  - 角色先比选多格 Footprint 与组合路径（示例：买下一座他人建筑 + 再占一块空地，总成本最低）；比选须遵守「AI 选址约束」
  - 审批详情须写清：申请者、目标建筑类型、各**未被覆盖**占格（哪格购地、哪格购置谁的建筑等）及费用概要；**被覆盖**格可注记但不计费、不购地
  - 异步检查须覆盖整单：**未被覆盖**的购地格仍可售、**未被覆盖**的购置格目标建筑仍在且估值仍可成交、合计费用仍支付得起、Footprint、占格覆盖与邻域规则仍满足
  - 示例 walkthrough：[beautiful-corners/multi-tile-workshop.md](beautiful-corners/multi-tile-workshop.md)

### 领主收回占格

- **规则**：领主若要收回某格上的土地，须向该格**建筑主人****询价**并按估值**买回建筑**；不得单方面无偿收回。
- **说明**：
  - 角色已向领主永久购得的土地，所有权在角色侧；领主不能重复售地或无偿夺地
  - 格上已有建筑时，领主收回须按**建筑回购**处理：卖方为建筑主人，买方为领主
  - **报价与成交价**与占格购置**规则一致**（当日建筑估值、无议价）；领主询价 → 收到估值 → **直接决定**购回或放弃；建筑主人被动应答
  - 成交前须校验领主**支付得起**且交易仍有效（建筑仍在、所有者未变等）

### 无空地则购置占格权

- **规则**：工作场所与住房均采用同一逻辑：找不到符合条件的空地时，改为向他人购置既有建筑所占格位。
- **说明**：
  - 购置对象是当前格上的建筑实例及其占格权，不是入住或使用原建筑功能
  - 住房与工作场所无不同的购置分支

### 购置即拆后自建

- **规则**：购置的含义是：付价取得占格权 → 拆掉原建筑 → 在同一格建造自己的目标建筑。
- **说明**：
  - 不存在「买下后继续当铁匠铺/继续当别人的茅舍用」的玩法路径
  - 卖方失去该格建筑；买方获得该格并在拆除后自建
  - 拆毁规则见「建筑拆毁」

### 建筑拆毁

- **规则**：拆毁建筑**暂不消耗**物料或劳动，**不回收**任何材料。
- **说明**：
  - 适用于购置后拆除、领主回购后清空等场景；后续若引入拆毁成本或回收机制再单独立项

### 购置询价：买方发起、比价选址

- **规则**：购置由买方发起；买方对多个候选格分别**询价**，选取报价最低者**直接决定**是否购买并完成交易。
- **说明**：
  - **候选格枚举**：对地图**全部格子**扫描，筛选通过买方目标建筑选址规则、且格上已有他人建筑的占格；**排除**建筑主人为领主（玩家）的格，见「AI 选址约束」
  - 每格询价独立；格上须有可估值的建筑实例，否则该格不可询价
  - 买方在**支付得起**的候选格中，选取报价最低者；无任一格满足则购置失败

### 占格建筑交易成交价

- **规则**：占格购置与领主回购的**报价与成交价**均为该格建筑实例的当日**建筑估值**（[building-valuation-calculator.md](building-valuation-calculator.md)）；**无议价**。
- **说明**：
  - 买方（角色购置或领主回购）询价 → 系统按估值计算器返回单一金额 → 买方**接受或放弃**；不存在还价、卖方保留价或反复出价
  - 卖方被动应答（返回估值即可），无需卖方 AI 参与定价决策
  - 成交时以询价时刻（或实现约定的重验时刻）的估值扣款；组合方案整单重验时须复算各购置格估值仍支付得起
  - 估值 v0 见 [building-valuation-calculator.md](building-valuation-calculator.md)（商业看净收入，住房看实际住房等级）
