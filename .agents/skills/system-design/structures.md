# 建筑 / 选址

## 已定决策

### 建筑分类

- **状态**：已定
- **规则**：建筑分「工作场所」与「住房」两类。
- **说明**：
  - 工作场所示例：铁匠铺
  - 住房示例：茅舍及更高级住宅
  - 具体类型列表与配置尚未定义

### 建造选址：先空地

- **状态**：已定
- **规则**：角色需要某类建筑时，先在地图上寻找满足该类型条件的空地；条件满足后须向领主购买地契并经领主同意，方可在该格建造。
- **说明**：
  - 「空地」指可占格且通过该建筑类型选址规则的位置（与代码现状的差异：当前仅检查格空，邻域/地形等规则待实现）
  - 高级住房等类型可要求周边存在指定设施（邻域规则按类型配置）
  - **地契仅适用于空地建造**；向他人购置占格（拆后自建）不走地契审批，见「无空地则购置占格权」
- **开放问题**：
  - 空地是否排除环境物占格（橡树、灌木、旌旗等）？
  - 各建筑类型的邻域/地形规则表？
  - 地契价格如何计算？

### 地契与领主审批

- **状态**：已定
- **规则**：角色在空地建造前，须向领主（玩家）申请购买地契；领主在界面中同意或拒绝；同意时须重新校验申请是否仍有效，无效则不得执行。
- **说明**：
  - 申请进入界面**待办队列**：队列中插入一项可点按钮
  - 点开展开详情界面，说明例如：「{角色}希望在{位置}建造{建筑类型}，需要购买地契」
  - **拒绝**：不签发地契，该次建造申请结束（角色后续行为待定）
  - **同意**：执行前再次验证，防止申请**过期**；校验失败则不同意建造（等同拒绝或需提示原因，实现待定）
  - **过期 / 失效条件（示例，非穷举）**：
    - 目标格已被占用（含领主或其它角色新造建筑）
    - 申请者当前金钱不足以支付地契（及约定的其它费用）
    - 选址规则不再满足（邻域设施被拆、地形变化等）
  - 校验通过后：完成地契交易（货币自申请者转至领主，见 [economy.md](economy.md)）并允许在该格开工建造
- **开放问题**：
  - 待办队列所属 UI 节点/场景？
  - 同意时校验失败给领主/角色的反馈文案？
  - 申请排队期间是否锁定该格（防抢建）？

### 无空地则购置占格权

- **状态**：已定
- **规则**：工作场所与住房均采用同一逻辑：找不到符合条件的空地时，改为向他人购置既有建筑所占格位。
- **说明**：
  - 购置对象是当前格上的建筑实例及其占格权，不是入住或使用原建筑功能
  - 住房与工作场所无不同的购置分支

### 购置即拆后自建

- **状态**：已定
- **规则**：购置的含义是：付价取得占格权 → 拆掉原建筑 → 在同一格建造自己的目标建筑。
- **说明**：
  - 不存在「买下后继续当铁匠铺/继续当别人的茅舍用」的玩法路径
  - 卖方失去该格建筑；买方获得该格并在拆除后自建
- **开放问题**：
  - 拆毁是否消耗物料/劳动时间？

### 购置询价：买方发起、比价选址

- **状态**：已定
- **规则**：购置由买方发起；买方对多个候选格分别向各格卖方询价，选取成交价最低者完成购置。
- **说明**：
  - 候选格为通过买方目标建筑选址规则、且格上已有他人建筑的占格
  - 每格询价独立，得到该格对应的最终成交价（见「出售权重计算器」）
  - 买方在**可成交且自身支付得起**的候选格中，选取成交价最低者；无任一格满足则购置失败
- **开放问题**：
  - 候选格枚举范围（全图 / 半径 / 数量上限）？

### 出售权重计算器

- **状态**：已定
- **规则**：占格购置价由出售权重计算器得出；先算不含金钱的对价权重，再反推使**总权重 == 0** 的金额，该金额即为该笔交易的最终成交价。
- **说明**：
  - 与 [characters.md](characters.md) 中转职权重计算器同构：非金钱因素汇总后，金钱作为补偿项参与总权重
  - 与佣金的差异：佣金为使总权重 **> 0** 的最低金额；出售为使总权重 **== 0** 的金额（卖方在此价上无保留、无额外索价）
  - 因素方向与列表尚未定义（示例：仍在使用、重置成本、区位稀缺、体面、急用钱等）
  - 占格权交易不适用 [economy.md](economy.md) 的同质「流通商品」日价公式；物料重置成本折钱时可引用当日商品市价
  - 若不存在有限金额能使总权重 == 0（例如非金钱权重过强且金钱项无法拉平），视为该格不可成交
- **开放问题**：
  - 非金钱因素列表与权重公式？
  - 金钱项与总权重的具体函数形式（线性、分段）？

## 设计示例：最美角落

> 下列数值与建筑名为**叙事用示例配置**，非全局平衡定案；用于串联已定流程。

**背景**：某角色原住简陋住房，积蓄后欲改建/迁入**奢侈住房**。该类型选址规则（示例）：以目标格为中心 **15 格**内须同时存在**酒馆**与**铁匠铺**（邻域设施由地图现状判定，非买方自带）。

**稀缺**：全图仅 **2 格**满足上述奢侈住房选址；两格皆已被占——分别为**木匠铺**、**澡堂**（工作场所）。无合格空地 → 走「购置占格权」分支。

**询价与成交**（买方发起）：

1. 对两格各向当前占格所有者询价 → 出售权重计算器给出各格最终价（总权重 == 0 的金额）。
2. 澡堂格报价低于木匠铺格，且买方**支付得起**澡堂价。
3. 买方在可成交且支付得起的候选格中取**最低价** → 选中澡堂格。
4. 付价 → **拆掉澡堂** → 在同一格**自建奢侈住房**。

**要点**：奢侈条件由**周边已有**酒馆/铁匠铺满足；买方买的是「稀缺区位上的占格权」，不是澡堂或木匠铺的功能。两格同享同一套周边设施时，比价发生在**不同卖方、不同实例**的拆买价之间。
