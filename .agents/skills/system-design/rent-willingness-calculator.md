# 租意愿计算器

> 汇总各因素**得分**，输出角色对某**住房等级**床位的租住意愿及租金区间。与 [career-change-willingness-calculator.md](career-change-willingness-calculator.md)（雇佣/转职）分离。床位挂牌与日更见 [commerce.md](commerce.md)「床位挂牌租金」；寻租与自建优先级见 [needs.md](needs.md)「住房需求：先租后建」。

### 核心机制

- **规则**：输入**角色**、目标**实际住房等级**（或与之对应的等级档位）、**当前挂牌日租**（评估是否续租/离店时），输出：
  - **最高可出租金**：该角色在当前**生活水平**下，愿为该等级床位支付的**日租上限**；
  - **保证正收入的最低租金**：支付后**日结余仍为正**的租金额**上限**（即 affordability 硬顶；命名沿用，实为「正收入意义下的租金上限」）；
  - **租意愿得分**：综合得分；**< 0** 表示不愿续住/不应租入。
- **说明**：
  - 各因素得分函数与权重**实现期调试**，不在设计阶段定数值公式
  - **不是**独立租金价表；挂牌价由 [commerce.md](commerce.md) 市场日更规则决定

- **说明**：
  - **正面**：挂牌日租**低于**最高可出越多、实际住房等级**超出**当前生活水平需求的冗余越多、等
  - **负面**：日租**高于**保证正收入的最低租金（ affordability 顶）、与当前劳动获益/刚性日耗不匹配、等
  - 输入中的**当前挂牌日租**仅用于评估**已有租约**或**指定候选床位**；寻租比价时由流程传入各床挂牌价

### 自住

- **规则**：角色评估**居住在自己为建筑主人的建筑**内、且**占用该建筑床位**时，**租意愿得分固定为 100**（视为必留）。
- **说明**：
  - **硬约束**仍适用：若**实际住房等级**不满足当前生活水平住房条件，**不得**以自住满足住房需求（与得分无关）
  - 汇总**等级租金区间**、同等级**平均挂牌价**等市场统计时，**排除**「建筑主人占自家床」的样本（主人不参与租赁市场的最高可出统计）

### 离店与寻租

- **规则**：角色对**当前居住地**每日调用本计算器；若**租意愿得分 < 0**，**退租/离店**并在下一逻辑步**寻租**（见 [needs.md](needs.md)）。
- **说明**：
  - **接受新租约**：对候选床位传入挂牌日租，仅当**租意愿得分 ≥ 0** 且**实际住房等级**满足需求时方可租入
  - 寻租时在得分 **≥ 0** 的候选中优先**挂牌日租更低**者（实现 tie-break 可再定）

### 等级租金区间（供挂牌 clamp）

- **规则**：每个**实际住房等级**（或等级档位）维护全场 **R_min**、**R_max**，供 [commerce.md](commerce.md) 床位挂牌日更 **clamp**；由对该等级的租户计算器输出（**不含**主人自住样本）滚动汇总（具体聚合函数实现期调试）。
- **说明**：
  - 无历史样本时，**R_min**、**R_max** 由配置表给出该等级缺省上下界
