# 经济 / 货币

### 货币总量恒定

- **规则**：游戏世界中的货币总量恒定；货币在玩家（领主）与角色之间流通。
- **说明**：
  - 货币不因时间流逝或系统事件凭空增减总量
  - 流通主体为领主（玩家）与场内角色；转移即一方减少、另一方增加
  - 领主持有的货币计入总量，但**不计入**定价用的「流通货币」（见下）
- **开放问题**：见 [open-decisions.md](open-decisions.md) **E5**、**X1–X2**

### 流通货币

- **规则**：玩家（领主）以外角色持有的货币，计为「流通货币」。
- **说明**：
  - 用于价格计算中的「流通货币总量」
  - 领主钱包不参与该统计

### 流通商品

- **规则**：每人产生需求；持有量超出需求的部分，计为「流通商品」。
- **说明**：
  - 用于价格计算中的「流通商品总量」
  - 需求的具体定义与计算方式：见 [open-decisions.md](open-decisions.md) **E4**

### 社会必要劳动时间

- **规则**：所有生产行为须记录耗时，用于统计社会必要劳动时间。
- **说明**：
  - 生产行为的时间数据是价格形成的输入之一
  - 统计口径：见 [open-decisions.md](open-decisions.md) **E3**
  - 建筑类劳动时间亦供给 [building-valuation-calculator.md](building-valuation-calculator.md)（建筑估值）

### 价格形成

- **规则**：商品价格由社会必要劳动时间、流通货币总量、流通商品总量、上一天价格共同决定；先算期望价格，再从上一天价格向期望价格小幅调整。
- **说明**：
  - 每日（或每个价格更新周期）更新一次
  - 期望价格公式与调整算法：见 [open-decisions.md](open-decisions.md) **E1–E2**
- **开放问题**：见 [open-decisions.md](open-decisions.md) **E1–E4**
