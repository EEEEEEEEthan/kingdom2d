# 经济 / 货币

### 格子通行频数

- **规则**：每个**地图格**维护**当日通行频数**；任意角色**进入**该格时 **+1**；**每个游戏日**初（实现约定时刻）**清零**后重新累计。
- **说明**：
  - 「进入」以格坐标变化为准，同一格内移动不计
  - 频数仅用于早市个人摊位选址，见「早市个人摆摊」

### 摊位

- **规则**：**摊位**为独立于**建筑**的场上实体类型；早市个人摆摊时于选定格上生成，早市结束移除。
- **说明**：
  - **非建筑**：不占建筑占格逻辑，不替代、不拆除既有建筑
  - **渲染层级**：摊位绘于**建筑之上**，**遮住**该格上**摆摊者**小人；**不遮**同格未摆摊角色与其他格角色；摊位整体位于**地形层之下**（被地形盖住）
  - 一格同时至多一个个人摊位；该格是否「已被占用」以是否已有个人摊位为准

### 早市

- **规则**：**早市**时段内发生场内流通交易，分两类卖方：**角色个人摆摊**（经**摊位**实体）与**建筑铺面代摊**（无人值守，见 [commerce.md](commerce.md)「早市铺面代摊」）；**全部**场内角色（含旅行商人）按「早市来访者遍历」参与买卖；成交价统一为各品种**当日市价**（见「价格形成」）；**首版不支持挂单**（预先标价、要约持续至撤单的非即时成交）。
- **说明**：
  - 时段边界见 [time.md](time.md)「日内四时段」
  - 个人摆摊选址与来访者遍历见下两节；铺面代摊挂出品种与数量实现期定
  - 旅行商人与常驻角色规则相同

### 早市个人摆摊

- **规则**：每个**游戏日**、**早市**开始时，对每名场内角色独立掷 **30%** 概率决定是否**出摊**；若出摊，在**通行频数降序**的格列表中选取**首个未被个人摊位占用**的格放置摊位，摆摊者驻留该格；出售其持有量超出**预期库存**的实物（见「预期库存」「流通商品」），收入进角色账本。
- **说明**：
  - 频数并列时的 tie-break 实现期定
  - 未出摊者照常参与「早市来访者遍历」

### 早市来访者遍历

- **规则**：早市时段内，每名参与者将当日全部**卖方点位**（个人摊位格 + 当日挂出铺面代摊的建筑格）组成列表，以**随机顺序**逐点访问；在每个点位与对应卖方**一次性**完成当次交易——**购买**自身**需求**侧缺口商品，**出售**自身超出预期库存的实物；然后前往下一点位。
- **说明**：
  - **一次性**：每点位每来访者仅一轮即时成交，无挂单、无跨日要约
  - **需求**侧：生活类按**标签**缺口（含 [needs.md](needs.md)「饱食」等）；旅行商人按特殊标签需求（见「旅行商人」）
  - **出售**侧：与「流通商品」超出预期库存部分一致，按**具体品种**分账
  - 单笔数量上限、同点位买卖先后顺序、支付不起时的裁剪实现期定
  - 建筑铺面代摊成交收入进建筑账本；个人摊位成交收入进摆摊角色账本

### 资源与标签

- **规则**：每种**资源**（具体品种，如浆果、苹果、简易建材）可带一个或多个**标签**；角色与系统的**需求**针对**标签**表达，而非针对某一具体品种。
- **说明**：
  - 示例：浆果、苹果均带标签 **【食物】**；角色产生的是对 **【食物】** 的需求，任一带该标签的资源均可满足
  - 建造、生产、交易、**定价**在层内仍操作**具体资源品种**；**需求与预期库存**按**标签**表达（见「预期库存」）

### 货币总量恒定

- **规则**：**常驻场内**主体（领主 + 场内角色）开局货币总量 **10000**；常驻主体之间转移不改变总量。
- **说明**：
  - 领主持有的货币计入总量，但**不计入**定价用的「流通货币」（见下），且**不参与**商品估值中位数样本（见 [goods-valuation-calculator.md](goods-valuation-calculator.md)）
  - 开局分配见「开局货币分配」
  - **旅行商人**入境携款、离境带走，**角色离场**带走资源时，场内货币总量相应增减，见「旅行商人」「角色离场与死亡」

### 角色离场与死亡

- **规则**：角色**离场**时，带走其持有的**全部资源**（货币与物资）；场内货币总量与资源相应减少，不再计入流通统计。
- **说明**：
  - **死亡**机制暂不设计；死亡时货币与资源如何处理**暂不处理**
  - 离场与旅行商人离境类似，均属「资源离开场内」；是否补位、新角色加入等待后续设计

### 旅行商人

- **规则**：**旅行商人**偶尔途径玩家领土，停留**数日**后离开；在境期间与**常驻角色**一样计入**流通货币**及**商品估值中位数**样本；入境携款与货物，离境带走剩余货币与物资。
- **说明**：
  - **需求**：随机生成**特殊标签需求**（非常驻角色的常规生活需求）；**不**像普通人一样需要进食（【食物】）或建造住房
  - **供给**：入境时携带一批**流通商品**（具体品种随机生成），在场内交易
  - 出现频率、停留天数、特殊需求与货物池等待内容配置

### 开局货币分配

- **规则**：开局一次性分配总量 **10000**；遵从**二八原则**：领主（玩家）得 **80%**（8000），场内全部角色合计得 **20%**（2000）。
- **说明**：
  - 角色侧 2000 **随机**分给各角色（不必均等、不必预先设计）
  - 仅分配一次，后续仅通过交易流转

### 流通货币

- **规则**：玩家（领主）以外**场内主体**持有的货币，计为「流通货币」；含场内角色与在境期间的**旅行商人**。
- **说明**：
  - 可作为 [goods-valuation-calculator.md](goods-valuation-calculator.md) 个人估值的**加性因素**（示例：持有现金）
  - 领主钱包不参与该统计；商人离境后其货币不再计入

### 预期库存

- **规则**：每名角色的**生活类需求**按**标签**设定**预期库存**；持有量超出标签预期库存的部分才计入流通（见「流通商品」）。**建造材料**仍按**具体资源品种**计预期库存。
- **说明**：
  - **生活物资**：标签 **【食物】** 的预期库存 = 该角色**当前生活水平等级**所对应条件中的【食物】储备天数（见 [needs.md](needs.md)「生活水平阶梯」）；未配置住房等级前的首档以配置表最低级为准
  - **建造计划**：当角色有需要建造的建筑时，预期库存**另计**该建筑配置所需**各具体材料**的数量（非标签）
  - **旅行商人**不适用上述生活/建造预期库存，改按随机**特殊标签需求**计（见「旅行商人」）
  - 预期库存随角色状态、建造计划变化而更新

### 流通商品

- **规则**：**生活类**：角色在某**标签**下各品种持有量之和超出该**标签**预期库存时，超出部分按**具体品种**分别计入流通商品；全场同品种流通量之和为「流通商品总量」。**建造材料**等按具体品种：持有量超出该品种预期库存的部分计入流通。
- **说明**：
  - 流通量作为 [goods-valuation-calculator.md](goods-valuation-calculator.md) 的**当日快照**输入（示例：某品种流通很多 → 乘性因子）
  - 标签预期库存定义见上节；标签内超出量如何分摊至各品种实现期定

### 价格形成

- **规则**：**每个游戏日**、每个**具体品种**：对计入样本的全部主体调用 [goods-valuation-calculator.md](goods-valuation-calculator.md) 得**个人估值**，取**中位数**为 **raw 中位价**；**当日市价** = 对 **raw 中位价**与**上日市价**做平滑（**上日价参与**；平滑函数实现期调试）。
- **说明**：
  - **领主不参与**中位数样本
  - 早市成交、 [labor-benefit.md](labor-benefit.md) 产出市值、建造材料引用等，均使用**当日市价**
  - **需求按标签、市价按品种**：角色消费与储备看标签；交易与定价仍按**具体资源品种**分账
