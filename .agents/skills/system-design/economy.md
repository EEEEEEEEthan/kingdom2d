# 经济 / 货币

### 货币总量恒定

- **规则**：游戏世界中的货币总量恒定（**10000**）；货币在玩家（领主）与角色之间流通。
- **说明**：
  - 货币不因时间流逝或系统事件凭空增减总量
  - 流通主体为领主（玩家）与场内角色；转移即一方减少、另一方增加
  - 领主持有的货币计入总量，但**不计入**定价用的「流通货币」（见下）
  - 开局分配见「开局货币分配」
- **开放问题**：见 [open-decisions.md](open-decisions.md) **X1–X2**

### 开局货币分配

- **规则**：开局一次性分配总量 **10000**；遵从**二八原则**：领主（玩家）得 **80%**（8000），场内全部角色合计得 **20%**（2000）。
- **说明**：
  - 角色侧 2000 **随机**分给各角色（不必均等、不必预先设计）
  - 仅分配一次，后续仅通过交易流转

### 流通货币

- **规则**：玩家（领主）以外角色持有的货币，计为「流通货币」。
- **说明**：
  - 用于价格计算中的「流通货币总量」
  - 领主钱包不参与该统计

### 预期库存

- **规则**：每名角色对每种商品各有**预期库存**；持有量超出预期库存的部分才计入流通（见「流通商品」）。
- **说明**：
  - **生活物资**（示例）：每人储备 **3 天**食物消耗量；拥有超出 3 天份量的部分成为流通商品
  - **建造计划**：当角色有需要建造的建筑时，预期库存**包含**该计划所需**建筑材料**的部分
  - 预期库存随角色状态、建造计划变化而更新

### 流通商品

- **规则**：角色某商品**持有量**超出其**预期库存**的部分，计为该角色对该商品的流通商品；全场同类流通商品之和为「流通商品总量」。
- **说明**：
  - 用于价格计算中的「流通商品总量」（期望价格与之负相关，见「期望价格与参数相关性」）
  - 预期库存定义见上节

### 社会必要劳动时间

- **规则**：所有生产行为须记录耗时；按**商品**分别统计，取**均值** = 累计生产总耗时 ÷ 累计生产总量。
- **说明**：
  - 每次生产：累计生产总耗时增加本次耗时，累计生产总量增加本次产量，二者相除即得当前均值
  - 生产行为的时间数据是价格形成的输入之一
  - 建筑建造须记时；按**建筑类型**同理累计耗时与完成次数求均值，供给 [building-valuation-calculator.md](building-valuation-calculator.md)（建筑估值）

### 近一年消费总量

- **规则**：统计近**一个游戏年**（滚动最近 12 个游戏月，见 [overview.md](overview.md)）内全场**消费**的该商品总量，作为期望价格的输入之一。
- **说明**：
  - **凡消费行为一律计入**，不设事件类型白名单或排除；凡使该商品持有量减少的流出，均计入
  - 按**商品**分别累计；事件时间戳落在窗口内即纳入
  - 期望价格与该总量**正相关**：消费越多，期望价格越高

### 近一年生产总量

- **规则**：统计近**一个游戏年**（滚动最近 12 个游戏月）内全场**生产**的该商品总量，作为期望价格的输入之一。
- **说明**：
  - **凡生产行为一律计入**，不设事件类型白名单或排除；凡使该商品持有量增加的来源，均计入
  - 按**商品**分别累计；事件时间戳落在窗口内即纳入
  - 期望价格与该总量**负相关**：生产越多，期望价格越低

### 期望价格与参数相关性

- **规则**：期望价格与各输入参数的**单调方向**如下（**不必**先定具体公式，实现时须满足这些相关性）：

| 参数 | 与期望价格 |
|------|------------|
| 社会必要劳动时间 | **正相关** |
| 流通货币总量 | **正相关** |
| 近一年消费总量 | **正相关** |
| 流通商品总量 | **负相关** |
| 近一年生产总量 | **负相关** |

- **说明**：
  - 各参数按**商品**分别取值（分商品期望价）
  - 具体函数形式（如何组合、是否含交叉项）实现期调试，须满足上表单调方向
  - 上日价不参与期望价计算，仅用于日调整（见「价格形成」）

### 价格形成

- **规则**：先按上文参数与相关性算出**期望价格**，再从上一天价格向期望价格小幅调整，得到当日价格。
- **说明**：
  - 每日（或每个价格更新周期）更新一次
  - 期望价公式与日调整的具体算法实现期调试，须满足「期望价格与参数相关性」的单调约束
