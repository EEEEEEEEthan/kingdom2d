# 经济 / 货币

### 早市

- **规则**：**早市**时段内发生场内流通交易，分两类卖方：**角色个人摆摊**与**商业建筑铺面代摊**（无人值守，见 [commerce.md](commerce.md)）；买方为在场内参与早市活动的角色（含旅行商人）。
- **说明**：
  - **个人摆摊**：角色以一定概率出摊，出售其背包中超出预期库存的实物；卖方为角色，收入进角色账本
  - **铺面代摊**：商业建筑出售建筑库存实物；卖方为建筑实例，收入进建筑账本
  - 成交价取成交时刻该品种的**当日市价**（见「价格形成」）；成交计入该品种的近一年产消统计
  - 个人是否摆摊、代摊挂哪些品种与数量、买家选购逻辑实现期定；旅行商人可买可卖，规则与常驻角色相同

### 资源与标签

- **规则**：每种**资源**（具体品种，如浆果、苹果、简易建材）可带一个或多个**标签**；角色与系统的**需求**针对**标签**表达，而非针对某一具体品种。
- **说明**：
  - 示例：浆果、苹果均带标签 **【食物】**；角色产生的是对 **【食物】** 的需求，任一带该标签的资源均可满足
  - 建造、生产、交易、**定价**在层内仍操作**具体资源品种**；**需求与预期库存**按**标签**表达（见「预期库存」）

### 货币总量恒定

- **规则**：**常驻场内**主体（领主 + 场内角色）开局货币总量 **10000**；常驻主体之间转移不改变总量。
- **说明**：
  - 领主持有的货币计入总量，但**不计入**定价用的「流通货币」（见下）
  - 开局分配见「开局货币分配」
  - **旅行商人**入境携款、离境带走，**角色离场**带走资源时，场内货币总量相应增减，见「旅行商人」「角色离场与死亡」

### 角色离场与死亡

- **规则**：角色**离场**时，带走其持有的**全部资源**（货币与物资）；场内货币总量与资源相应减少，不再计入流通统计。
- **说明**：
  - **死亡**机制暂不设计；死亡时货币与资源如何处理**暂不处理**
  - 离场与旅行商人离境类似，均属「资源离开场内」；是否补位、新角色加入等待后续设计

### 旅行商人

- **规则**：**旅行商人**偶尔途径玩家领土，停留**数日**后离开；在境期间与**常驻角色**一样计入**流通货币**及期望价相关统计（产消、流通商品等）；入境携款与货物，离境带走剩余货币与物资。
- **说明**：
  - **需求**：随机生成**特殊标签需求**（非常驻角色的常规生活需求）；**不**像普通人一样需要进食（【食物】）或建造住房
  - **供给**：入境时携带一批**流通商品**（具体品种随机生成），在场内交易
  - 交易、消费、生产等行为与常驻角色同样计入近一年产消等价格形成输入
  - 出现频率、停留天数、特殊需求与货物池等待内容配置

### 开局货币分配

- **规则**：开局一次性分配总量 **10000**；遵从**二八原则**：领主（玩家）得 **80%**（8000），场内全部角色合计得 **20%**（2000）。
- **说明**：
  - 角色侧 2000 **随机**分给各角色（不必均等、不必预先设计）
  - 仅分配一次，后续仅通过交易流转

### 流通货币

- **规则**：玩家（领主）以外**场内主体**持有的货币，计为「流通货币」；含场内角色与在境期间的**旅行商人**。
- **说明**：
  - 用于价格计算中的「流通货币总量」
  - 领主钱包不参与该统计；商人离境后其货币不再计入

### 预期库存

- **规则**：每名角色的**生活类需求**按**标签**设定**预期库存**；持有量超出标签预期库存的部分才计入流通（见「流通商品」）。**建造材料**仍按**具体资源品种**计预期库存。
- **说明**：
  - **生活物资**：标签 **【食物】** 的预期库存 = 该角色**当前生活水平等级**所对应条件中的【食物】储备天数（见 [needs.md](needs.md)「生活水平阶梯」）；未配置住房等级前的首档以配置表最低级为准
  - **建造计划**：当角色有需要建造的建筑时，预期库存**另计**该建筑配置所需**各具体材料**的数量（非标签）
  - **旅行商人**不适用上述生活/建造预期库存，改按随机**特殊标签需求**计（见「旅行商人」）
  - 预期库存随角色状态、建造计划变化而更新

### 流通商品

- **规则**：**生活类**：角色在某**标签**下各品种持有量之和超出该**标签**预期库存时，超出部分按**具体品种**分别计入流通商品；全场同品种流通量之和为「流通商品总量」。**建造材料**等按具体品种：持有量超出该品种预期库存的部分计入流通。
- **说明**：
  - 用于价格计算中的「流通商品总量」（期望价格与之负相关，见「期望价格与参数相关性」）；市价仍按**具体品种**定价
  - 标签预期库存定义见上节；标签内超出量如何分摊至各品种实现期定

### 社会必要劳动时间

- **规则**：所有生产行为须记录耗时；按**商品**分别统计，取**均值** = 累计生产总耗时 ÷ 累计生产总量。
- **说明**：
  - 每次生产：累计生产总耗时增加本次耗时，累计生产总量增加本次产量，二者相除即得当前均值
  - 生产行为的时间数据是价格形成的输入之一
  - 建筑建造须记时；按**建筑类型**同理累计耗时与完成次数求均值，供给商品定价与经济平衡；建筑实例估值见 [building-valuation-calculator.md](building-valuation-calculator.md)（商业净收入 / 住房实际等级）

### 近一年消费总量

- **规则**：统计近**一个游戏年**（滚动最近 12 个游戏月，见 [overview.md](overview.md)）内全场**消费**的该商品总量，作为期望价格的输入之一。
- **说明**：
  - **凡消费行为一律计入**，不设事件类型白名单或排除；凡使该商品持有量减少的流出，均计入
  - 按**商品**分别累计；事件时间戳落在窗口内即纳入
  - 期望价格与该总量**正相关**：消费越多，期望价格越高

### 近一年生产总量

- **规则**：统计近**一个游戏年**（滚动最近 12 个游戏月）内全场**生产**的该商品总量，作为期望价格的输入之一。
- **说明**：
  - **凡生产行为一律计入**，不设事件类型白名单或排除；凡使该商品持有量增加的来源，均计入
  - 按**商品**分别累计；事件时间戳落在窗口内即纳入
  - 期望价格与该总量**负相关**：生产越多，期望价格越低

### 期望价格与参数相关性

- **规则**：期望价格与各输入参数的**单调方向**如下（**不必**先定具体公式，实现时须满足这些相关性）：

| 参数 | 与期望价格 |
|------|------------|
| 社会必要劳动时间 | **正相关** |
| 流通货币总量 | **正相关** |
| 近一年消费总量 | **正相关** |
| 流通商品总量 | **负相关** |
| 近一年生产总量 | **负相关** |

- **说明**：
  - 各参数按**商品**分别取值（分商品期望价）
  - 具体函数形式（如何组合、是否含交叉项）实现期调试，须满足上表单调方向
  - 上日价不参与期望价计算，仅用于日调整（见「价格形成」）

### 价格形成

- **规则**：先按上文参数与相关性算出**期望价格**，再从上一天价格向期望价格小幅调整，得到当日价格。
- **说明**：
  - 每日（或每个价格更新周期）更新一次
  - 期望价公式与日调整的具体算法实现期调试，须满足「期望价格与参数相关性」的单调约束
  - **需求按标签、市价按品种**：角色消费与储备看标签；期望价、产消统计、交易仍按**具体资源品种**分账，互不影响
