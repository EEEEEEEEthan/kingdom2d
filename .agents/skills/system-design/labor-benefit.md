# 劳动获益

> 衡量角色**从事某职业**所获得的经济获益；是跨职业比较、转职决策等系统的核心概念。与现金**收入**不同：获益可来自实物产出折算，亦可来自日薪。

## 已定决策

### 定义

- **状态**：已定
- **规则**：**劳动获益**指角色因当前职业在一段劳动时间内获得的经济获益总量；用于比较不同职业、评估转职诱因等。
- **说明**：
  - **不是**现金流入；自消、入库、未售出的产出均可能计入
  - **不是** [building-valuation-calculator.md](building-valuation-calculator.md) 的建筑估值，亦非领主钱包或流通货币统计
  - 日常比较与计算器输入通常取**一个游戏日**尺度的获益（下称**日劳动获益**），与 [characters.md](characters.md)「雇员薪酬结算」的日薪周期一致

### 按职业类型的计量

- **状态**：已定
- **规则**：劳动获益因职业类型而异，统一用下列两种方式之一计量：

| 职业类型 | 计量方式 | 计算 |
|----------|----------|------|
| **雇佣职业**（如管家） | **日薪** | 该岗位当日应付薪酬（现金）；无实物产出 |
| **自由职业**（如采浆果） | **产出市值** | 当日各产出商品的 `数量 × 市价` 之和 |

- **说明**：
  - 雇佣职业不生产可流通商品，获益即劳动换得的**日薪**（或雇佣关系下的按比例薪酬）
  - 自由职业不可仅用现金流入衡量（如采浆果自食无现金收入；食物短缺时采浆果的劳动获益仍可能最高）
  - 产出市值：自消、入库、售出均计入；未产出部分不计
  - 市价来源见 [economy.md](economy.md) 价格形成；具体取哪一更新周期的价格尚未确定

### 跨职业比较

- **状态**：已定
- **规则**：比较两种职业的劳动获益时，雇佣侧取**日薪**，自由侧取**产出市值**，在同一货币尺度下比大小。
- **说明**：
  - 日薪底价（雇佣议价）见 [characters.md](characters.md) 与 [career-change-calculator.md](career-change-calculator.md)；底价是「愿接受岗位的最低日薪」，与在岗日劳动获益相关但场景不同

### 转职权重（自由职业）

- **状态**：已定
- **规则**：对每个**候选自由职业**计算**转职权重**（以当前职业与目标职业的日劳动获益差为主，叠加其它待定非金钱因素）；**≤ 0 丢弃**，**> 0** 纳入当日抽取池；**不涉及金钱**。
- **说明**：
  - 权重计算不使用 [career-change-calculator.md](career-change-calculator.md)（该计算器仅用于雇佣日薪反推）
  - 具体函数形式（线性差、分段等）尚未确定

### 转职抽取

- **状态**：已定
- **规则**：
  - **自由职业日常转职**：每个游戏日对池中角色执行一次；在「**不转职**」空白权重与各候选自由职业的 **> 0** 权重间加权抽取；命中某自由职业则转职至该职业。
  - **雇佣职业离职**：与日常转职相同地列出各自由职业权重（≤ 0 丢弃），但**不设不转职空白**；必在 **> 0** 权重中加权命中某一自由职业。
- **说明**：
  - 日常抽取：候选权重均 ≤ 0 时，等价于仅能命中**不转职**空白
  - 离职抽取：候选权重均 ≤ 0 时的处理尚未确定
  - 转职与土地、占格无关，见 [characters.md](characters.md)

## 与其它概念的分工

| | 劳动获益 / 转职 | 日薪底价（转职计算器） | 建筑估值 |
|--|------------------|------------------------|----------|
| 问的问题 | 转职权重多少 / 抽中哪门自由职业 | 这人**愿以何日薪接受岗位** | 这栋楼**客观值多少** |
| 是否涉及金钱 | **否**（加权抽取） | **是**（反推临界日薪） | 是（估值金额） |
| 因职业类型 | 雇佣=日薪，自由=产出市值 | 仅雇佣场景 | 不适用 |
