# 劳动获益

> 衡量角色**从事某职业**所获得的经济获益；是跨职业比较、转职决策等系统的核心概念。与现金**收入**不同：获益可来自实物产出折算（完成时市价），亦可来自雇佣佣金。

### 定义

- **规则**：**劳动获益**指角色因当前职业在计量周期内获得的经济获益总量；用于比较不同职业、评估转职诱因等。
- **说明**：
  - **不是**现金流入；自消、入库、未售出的产出均可能计入
  - **不是** [building-valuation-calculator.md](building-valuation-calculator.md) 的建筑估值，亦非领主钱包或流通货币统计
  - 日常比较与计算器输入通常取**一个游戏日**尺度的获益（下称**日劳动获益**），与 [characters.md](characters.md)「雇员薪酬结算」的日薪周期一致

### 按职业类型的计量

- **规则**：劳动获益因职业类型而异，统一用下列两种方式之一计量：

| 职业类型 | 计量方式 | 计算 |
|----------|----------|------|
| **生产类自由职业**（如拾荒者、伐木工） | **产出市值** | 各次生产完成时，该次产出商品的 `数量 × **完成时刻**商品市价` |
| **雇佣类职业**（建筑工、商业雇员等） | **佣金** | 该岗位应付薪酬（日薪或雇佣关系下按比例折算的现金）；建筑自动产出不计入雇员产出市值 |

- **说明**：
  - 生产类自由职业不可仅用现金流入衡量（如自食无现金收入；短缺时采集类劳动获益仍可能最高）
  - 商业建筑雇员为**雇佣类**计量（佣金），与建筑被动产出分离，见 [commerce.md](commerce.md)「建筑自动生产」
  - 产出市值：自消、入库、售出均计入；未产出部分不计；市价取**生产完成时刻**的**当日市价**（见 [goods-valuation-calculator.md](goods-valuation-calculator.md)、[economy.md](economy.md)「价格形成」）
  - 雇佣类获益即劳动换得的**佣金**（与 [characters.md](characters.md)「雇员薪酬结算」一致）

### 平均劳动获益

- **规则**：转职意愿计算器分数模式比较各职业的**平均劳动获益**时，在统一货币尺度下，按职业类型分别计量后求该职业的平均日劳动获益。
- **说明**：
  - **生产类**：以历次生产完成时的产出市值为样本，汇总为日劳动获益后再求职业均值
  - **雇佣类**：以各次应付佣金为样本，汇总为日劳动获益后再求职业均值
  - 跨角色汇总范围与滑动窗口等实现细节实现期调试

### 角色详情展示

- **规则**：玩家可见的劳动获益**仅**在 [characters.md](characters.md)「角色详情」中展示；取该角色**最近一个游戏月**（7 游戏日）内各游戏日的日劳动获益**算术平均**。
- **说明**：
  - 按角色**实际从事职业**逐日计量（转职、雇佣变更后分段计入），非职业表全局均值
  - 与转职意愿计算器所用的职业平均劳动获益**可不同窗口**；意愿计算器窗口见上节「平均劳动获益」
  - 无独立劳动获益界面或调试面板

### 跨职业比较

- **规则**：比较两种职业的劳动获益时，生产类取**产出市值**，雇佣类取**佣金**，在同一货币尺度下比大小。
- **说明**：
  - 转职意愿计算器**分数模式**以目标职业与当前职业的**平均**日劳动获益比较为正面因素；**议价模式**无视劳动获益，反推日薪底价见 [career-change-willingness-calculator.md](career-change-willingness-calculator.md)

### 转职抽取

- **规则**：
  - 转职意愿计算器（分数模式）为 **x** 个候选自由职业各输出一个**转职权重**；**≤ 0 丢弃**，**> 0** 入池。
  - **日常转职**（自由职业与受雇者，见 [characters.md](characters.md)「日常转职」）：每个游戏日一次；**不转职空白权重** = `100 −` 池中各职业权重之和（不足 0 时按 0）；职业权重与空白权重合计 **100**，按权重随机抽取；**命中空白则不转职**（受雇者留任），命中某自由职业则转职（受雇者先解除雇佣）。
  - **雇佣职业离职**：仅对**满足任职条件**的候选自由职业计权重，**不设空白**；池中各权重 **> 0**（计算器保证，见 [career-change-willingness-calculator.md](career-change-willingness-calculator.md)「雇佣离职转自由职业」），加权抽取并**必转**一门自由职业。
- **说明**：
  - 日常抽取：池中无 **> 0** 权重时，空白权重为 100，等价于必不转职
  - 各职业权重之和超过 100 时，空白权重为 0；是否归一化实现期定
  - 离职抽取：雇佣结束瞬间角色**无职业**；判定时当前雇佣收入视为 **0**；可选候选至少一门（首版拾荒者无任职条件作保底）
  - 转职与土地、占格无关，见 [characters.md](characters.md)

## 与其它概念的分工

| | 转职意愿计算器·分数模式 | 转职意愿计算器·议价模式 | 建筑估值 |
|--|----------------------|----------------------|----------|
| 问的问题 | 转职权重多少 / 抽中哪门自由职业 | 愿以何**金额**（日薪）接受岗位 | 这栋楼**客观值多少** |
| 得分范围 | **所有因素**综合得分 | **除劳动获益外**的得分 + 反解金钱 | 估值金额 |
| 因职业类型 | 雇佣=佣金，生产类=产出市值 | 仅雇佣场景 | 不适用 |
