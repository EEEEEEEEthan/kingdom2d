# 建筑估值计算器

> 对**建筑实例**给出客观**估值**（货币金额）。与 [career-change-calculator.md](career-change-calculator.md)（雇佣日薪议价）分离。占格购置的报价与成交价即估值（无议价），见 [structures.md](structures.md)「占格建筑交易成交价」。

### 核心机制

- **规则**：输入建筑实例（类型、占格、实例状态、经营/邻域数据等），输出该实例在当前经济环境下的**估值**（单一金额，非区间）。
- **说明**：
  - **不是**日薪或购地价；不表达卖方主观保留价，亦无议价过程
  - **不是** [economy.md](economy.md) 中同质「流通商品」的日市价公式
  - **占格购置**：询价返回的报价与成交价**即**本估值（见 [structures.md](structures.md)「占格建筑交易成交价」）
  - **商业建筑**与**住房**采用**不同**的 v0 估值方向（见下）

### 商业建筑估值（v0）

- **规则**：工作场所等**商业建筑**的估值，**主要**依据该实例近**一个游戏年**（滚动最近 12 个游戏月）的**净收入**。
- **说明**：
  - 净收入 = 该建筑实例账本营业收入 − 营业支出（记账主体见 [commerce.md](commerce.md)；收支事件口径见 [open-decisions.md](open-decisions.md) X16）
  - 统计窗口与 [economy.md](economy.md)「近一年」一致
  - 具体金额如何由净收入映射为估值（线性、平滑、下限等）实现期调试

### 住房估值（v0）

- **规则**：**住房**的估值，**主要**依据该实例的**实际住房等级**；实际住房等级由配置**住房等级**与现场**服务等级**取**较小值**。
- **说明**：
  - **住房等级**：建筑类型配置上的等级（示例：茅舍 < 舒适宅 < 奢侈住房）
  - **服务等级**：由目标格**周围商业建筑覆盖**决定；按等级阶梯要求邻域内存在指定类型商业建筑（示例：2 级须覆盖**酒馆**，3 级还须覆盖**铁匠铺**；更高等级可继续叠加要求）
  - **实际住房等级** = `min(配置住房等级, 服务等级)`；二者取低，表示周边配套不足时住房「名实不符」
  - 实际住房等级是住房估值的**核心输入**；等级到金额的映射函数实现期调试
  - 服务等级判定半径、阶梯表与 [structures.md](structures.md)「住房等级与服务等级」、类型配置一致；奢侈住房选址示例见 [beautiful-corners/luxury-housing.md](beautiful-corners/luxury-housing.md)

### 共用与边界

- **规则**：估值按**建筑实例类型**分岔：商业走净收入模型，住房走实际住房等级模型。
- **说明**：
  - 购置占格时，估值对象是格上**现有**建筑实例（示例：买下澡堂格，按澡堂作为商业建筑的净收入估值，而非买方拟建的奢侈住房）
  - 物料与社会必要劳动时间仍由 [economy.md](economy.md) 统计，**不作为**本计算器 v0 的主输入
