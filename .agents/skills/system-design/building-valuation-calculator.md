# 建筑估值计算器

> 对**建筑实例**给出客观**估值**（货币金额），与 [career-change-calculator.md](career-change-calculator.md)（转职计算器）分离：后者决定当事人**愿不愿意、要什么成交价**；本计算器回答**这栋楼按规则值多少钱**。

## 已定决策

### 核心机制

- **状态**：已定
- **规则**：输入建筑实例（类型、占格、耐久/HP、建造记录等），输出该实例在当前经济环境下的**估值**（单一金额，非区间）。
- **说明**：
  - **不是**成交价、日薪或地契价；不表达卖方主观保留
  - **不是** [economy.md](economy.md) 中同质「流通商品」的日市价公式；商品市价可作为本计算器的**输入**（物料折钱）
  - 与转职计算器的关系：估值常作为转职计算器**非金钱因素**的输入之一（如重置成本、再建成本参照）；最终占格出售/回购价仍由转职计算器在 == 0 下反推，可与估值偏离

### 估值输入（概念层）

- **状态**：已定（方向已定，口径待定）
- **规则**：估值须能吸收下列类数据（具体公式未定的标为开放问题）：
  - **物料**：按建造或重置所需物料，以**当日商品市价**折钱（见 [economy.md](economy.md)）
  - **劳动**：该建筑类型对应的社会必要劳动时间（建造行为须记时，见 [economy.md](economy.md)「社会必要劳动时间」）
  - **实例状态**：如 HP / 完工度（含仅地基、填料未满的工地如何计价）
  - **类型与占格**：`StructureConfig`、单格或多格 Footprint
- **说明**：
  - 多格建筑、未竣工工地是否按完成态比例估值，尚未确定

## 与转职计算器的分工

| | 建筑估值计算器 | 转职计算器 |
|--|----------------|------------|
| 问的问题 | 这栋楼**客观值多少** | 这个人**愿以何价成交/接受岗位** |
| 输出 | 估值 | 临界金额（>0 或 ==0） |
| 典型用途 | 重置成本参照、UI 展示、非金钱因素输入 | 雇工日薪、占格出售最终价、领主回购成交价 |
| 是否因人而异 | 否（同一实例同一时刻应一致） | 是（同一栋楼，不同卖方报价可不同） |

## 已定用途（按场景）

| 场景 | 文档 | 说明 |
|------|------|------|
| 占格出售的非金钱因素 | [structures.md](structures.md) | 估值（或重置成本）可作为卖方「除钱以外权重」的输入；**最终成交价**仍由转职计算器 == 0 得出 |
| 物料/劳动记账与平衡 | [economy.md](economy.md) | 劳动时间统计、商品市价供给估值折钱 |
| （待定）领主购地价、税费、保险等 | — | 尚未纳入设计 |

## 开放问题

- 社会必要劳动时间按类型的聚合口径（均值、中位数、最近 N 次建造）？
- 工地阶段（地基、填料中、待雇工）估值是否按完成度比例？
- 区位稀缺是否进入**估值**还是只进入**转职计算器**非金钱项？
- 估值是否每日随商品市价刷新？
