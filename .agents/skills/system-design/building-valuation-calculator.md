# 建筑估值计算器

> 对**建筑实例**给出客观**估值**（货币金额）。与 [career-change-willingness-calculator.md](career-change-willingness-calculator.md)（雇佣日薪议价）分离。占格购置的报价与成交价即估值（无议价），见 [structures.md](structures.md)「占格建筑交易成交价」。

### 核心机制

- **规则**：输入建筑实例（类型、占格、实例状态、经营/邻域数据等），输出该实例在当前经济环境下的**估值**（单一金额，非区间）。
- **说明**：
  - **不是**日薪、购地价或床位日租；不表达卖方主观保留价，亦无议价过程
  - **不是** [economy.md](economy.md) 中同质「流通商品」的日市价公式
  - **占格购置**：询价返回的报价与成交价**即**本估值（见 [structures.md](structures.md)「占格建筑交易成交价」）
  - **全部建筑类型**走**同一**估值流程（见下）；**最终估值**取各层结果合成（见「估值合成」）

### 创值估值（v0）

- **规则**：建筑估值**主要**依据该建筑经济单位的 **创值·最近 1 游戏年**（滚动最近 12 个游戏月的日均创值）。
- **说明**：
  - 建筑创值 = **实际出售商品**收入 + **床位租金**收入（含外租与主人自租，见 [economy.md](economy.md)「创值」、[commerce.md](commerce.md)「建筑创值」）；**不含**日税、雇员薪酬、原料等支出
  - 统计窗口与 [economy.md](economy.md)「创值」一致
  - 具体金额如何由创值映射为估值（线性、平滑等）实现期调试

### 类型保底估值

- **规则**：当创值样本不足或映射结果低于配置**类型保底估值**时，估值取**保底值**（按建筑类型配置，与 Footprint、配置住房等级等相关）。
- **说明**：
  - 用于新建、空床、尚未产生售品/租金历史的建筑，避免占格购置价塌缩
  - **实际住房等级**不直接进入购置估值公式，仅影响居住品质与 [needs.md](needs.md)；见 [structures.md](structures.md)「住房等级与服务等级」

### 竣工保护加成

- **规则**：建筑实例**竣工**后 **1 个游戏月**内（**7 个游戏日**，见 [time.md](time.md)），叠加**竣工保护加成**（货币金额）；加成自竣工当日起**线性递减**，第 **7** 游戏日结束后**归零**。
- **说明**：
  - **目的**：抬高新建建筑占格购置价，避免刚竣工即被他人购置拆毁；买方须**支付得起**当日估值方可成交
  - **峰值**按建筑类型配置（实现期调试「非常高」相对基础估值的倍率或固定额）
  - **递减**：设 **d** 为竣工后已完整经过的游戏日数（竣工当日 **d = 0**），加成 = `峰值 × max(0, 1 − d / 7)`；**d ≥ 7** 时加成为 **0**（首月过完恰好失去）
  - **竣工时刻**以 [structures.md](structures.md)「建造施工流程」中建筑工施工完成、实例落成为准；**购置后拆毁再自建**的新实例重新起算
  - 加成**仅**影响占格购置**报价/成交价**，**不**改变该实例创值统计

### 估值合成

- **规则**：**最终估值** = **基础估值** + **竣工保护加成**（若未过期）；**基础估值** = `max(创值映射结果, 类型保底估值)`。
- **说明**：
  - 创值映射函数实现期调试；样本不足时基础估值通常取类型保底
  - 占格购置、组合方案询价与成交均使用**当日**最终估值

### 边界

- **规则**：购置占格时，估值对象是落点上**现有**建筑实例及其创值历史（示例：买下澡堂，按澡堂实例估值，而非买方拟建类型）。
- **说明**：
  - 物料仍由 [economy.md](economy.md) 定义品种与标签；**不作为**本计算器 v0 的主输入
