# 建筑估值计算器

> 对**建筑实例**给出客观**估值**（货币金额）。与 [career-change-calculator.md](career-change-calculator.md)（雇佣日薪议价）分离。占格购置的报价与成交价即估值（无议价），见 [structures.md](structures.md)「占格建筑交易成交价」。

### 核心机制

- **规则**：输入建筑实例（类型、占格、实例状态、经营/邻域数据等），输出该实例在当前经济环境下的**估值**（单一金额，非区间）。
- **说明**：
  - **不是**日薪、购地价或床位日租；不表达卖方主观保留价，亦无议价过程
  - **不是** [economy.md](economy.md) 中同质「流通商品」的日市价公式
  - **占格购置**：询价返回的报价与成交价**即**本估值（见 [structures.md](structures.md)「占格建筑交易成交价」）
  - **全部建筑类型**走**同一**估值流程（见下）

### 净收入估值（v0）

- **规则**：建筑估值**主要**依据该实例近**一个游戏年**（滚动最近 12 个游戏月）的**净收入**。
- **说明**：
  - 净收入 = 建筑账本**收入**（含**床位租金**、营业/代摊等）− **支出**（含**日税**、**雇员薪酬**、物料等；记账主体见 [commerce.md](commerce.md)；收支口径见 [open-decisions.md](open-decisions.md) D13）
  - 统计窗口与 [economy.md](economy.md)「近一年」一致
  - 具体金额如何由净收入映射为估值（线性、平滑等）实现期调试

### 类型保底估值

- **规则**：当净收入样本不足或映射结果低于配置**类型保底估值**时，估值取**保底值**（按建筑类型配置，与 Footprint、配置住房等级等相关）。
- **说明**：
  - 用于新建、空床、尚未产生租金/营业历史的建筑，避免占格购置价塌缩
  - **实际住房等级**不直接进入购置估值公式，仅影响居住品质与 [needs.md](needs.md)；见 [structures.md](structures.md)「住房等级与服务等级」

### 边界

- **规则**：购置占格时，估值对象是格上**现有**建筑实例及其账本历史（示例：买下澡堂格，按澡堂实例估值，而非买方拟建类型）。
- **说明**：
  - 物料与社会必要劳动时间仍由 [economy.md](economy.md) 统计，**不作为**本计算器 v0 的主输入
