# 角色 / 职业

## 已定决策

### 职业分类

- **状态**：已定
- **规则**：角色拥有职业；职业分「自由职业」与「雇佣职业」两类。
- **说明**：
  - 两类职业的具体列表尚未全部定义；**建筑工**为已确认职业之一（见「建筑工与施工」）
  - 同一角色是否可同时拥有两类、或互斥，尚未确定

### 自由职业转职

- **状态**：已定
- **规则**：每个**游戏日**，每名**自由职业**角色进行一次转职判定：列出全部自由职业的转职权重（见 [labor-benefit.md](labor-benefit.md)），**≤ 0 丢弃**，**> 0** 参与加权抽取；另设**不转职**空白权重；命中某职业则转职。
- **说明**：
  - 候选不含雇佣职业；上岗走「雇佣选人」
  - 转职与土地、占格无关
  - 空白权重数值与权重函数形式尚未确定

### 雇佣职业离职

- **状态**：已定
- **规则**：角色**不再需要**当前雇佣岗位时，执行与「自由职业转职」相同的权重列举与抽取（≤ 0 丢弃，> 0 入池），但**不设不转职空白**；必在池中命中某一自由职业。
- **说明**：
  - 触发时机（岗位撤销、任期届满、建筑竣工等）尚未按场景穷举
  - 池中无任何 > 0 权重时的处理尚未确定

### 劳动获益

- **状态**：已定
- **规则**：角色职业经济获益的统一概念为**劳动获益**；雇佣职业按**日薪**计量，自由职业按**产出市值**计量；跨职业比较规则见 [labor-benefit.md](labor-benefit.md)。

### 雇佣佣金与日薪底价

- **状态**：已定
- **规则**：单角色接受某一雇佣岗位所需的**日薪底价**，由 [career-change-calculator.md](career-change-calculator.md) 在**接受阈值（> 0）**下反推，非独立定价表。
- **说明**：
  - 支付方随场景而定（领主、建造方角色等），见 [economy.md](economy.md)
  - 与自由职业互转无关

### 雇佣选人

- **状态**：已定
- **规则**：需要填补某雇佣岗位时，对场内**每一名角色**（**含发起雇佣者本人**）求该岗位日薪底价，选用**底价最低**且有解者；细节见 [career-change-calculator.md](career-change-calculator.md)「雇佣选人」。
- **说明**：
  - 自己雇自己用于收入统计；**玩家 UI 不展示「自己雇佣自己」**
  - 建筑工场景见「雇佣建筑工」

### 建筑工与施工

- **状态**：已定
- **规则**：任何建筑的**施工完成**必须由**建筑工**职业执行；其它角色不得独自将工地从「待施工」变为竣工建筑。
- **说明**：
  - 占地、购地审批、购置占格、地基与填料等由建造责任方完成，见 [structures.md](structures.md)「建造施工流程」
  - 建筑工属于自由职业还是雇佣职业、是否须转职上岗，尚未确定

### 雇佣建筑工

- **状态**：已定
- **规则**：工地材料填满后，建造责任方须按「雇佣选人」雇**建筑工**完成施工（岗位=建筑工；雇主可为被选中的本人）。
- **说明**：
  - 雇佣关系建立后，薪酬按「雇员薪酬结算」执行
- **开放问题**：
  - 是否仅建筑工可被雇，还是任意职业可被临时雇作建筑工？

### 雇员薪酬结算

- **状态**：已定
- **规则**：雇员薪酬自**入职时刻**起算；**每个游戏日**结算一次；**离职时**再结算一次未结清部分。不足一整游戏日的时段按**比例**折算日薪。
- **说明**：
  - 游戏日长度与 [overview.md](overview.md) 时间系统一致（`all_days` 的整数日为界，一日 = 游戏 24 小时）
  - **按比例示例**：
    - 入职当日：自入职时刻至**当日结束**（下一游戏日 0 点）的时长 / 1 游戏日 × 日薪
    - 离职当日：自**当日 0 点**至离职时刻的时长 / 1 游戏日 × 日薪（若入职与离职在同一游戏日内，则为入职至离职的时长 / 1 游戏日 × 日薪）
  - 日薪取雇佣成立时锁定的底价，还是每日按 [career-change-calculator.md](career-change-calculator.md) 重算，尚未确定
- **开放问题**：
  - 薪酬结算时刻（午夜、早市开始等）？
  - 建造方欠薪、雇员罢工等行为？
