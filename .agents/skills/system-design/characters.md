# 角色 / 职业

### 角色离场

- **规则**：角色**离场**时带走其**全部资源**（货币、物资等）；详见 [economy.md](economy.md)「角色离场与死亡」。
- **说明**：
  - **死亡**首版暂不实现；工地欠薪/死亡清场见 [structures.md](structures.md)「工地异常（欠薪与死亡）」；死亡时货币/物资归属见 [economy.md](economy.md)「角色离场与死亡」

### 职业分类

- **规则**：角色通常拥有**唯一**当前职业；职业分「**自由职业**」与「**雇佣职业**」两类，**互斥**——**受雇期间不算**任何自由职业；**雇佣岗位结束瞬间**可短暂**无职业**，随即经「雇佣职业离职」抽选落回自由职业。
- **说明**：
  - **建筑工**为**雇佣职业**（见「建筑工与施工」）
  - **商业建筑雇员**为**雇佣职业**，各建筑类型的雇员岗对应**具名雇佣职业**（示例：铁匠铺雇员为**铁匠**），须绑定开放**上岗窗口**的建筑实例（见 [commerce.md](commerce.md)「建筑雇员」「上岗窗口与营业」）
  - 首版**自由职业**仅 **拾荒者**、**伐木工**（见「首版自由职业」）
  - 角色详情「当前职业」展示上述唯一职业名（受雇时展示雇佣职业名，非自由职业名）

### 首版自由职业

- **规则**：首版开放两种**生产类自由职业**：**拾荒者**、**伐木工**；角色在**工作**时段执行对应生产劳动，产出计入劳动获益（产出市值，见 [labor-benefit.md](labor-benefit.md)）。
- **说明**：
  - 单次劳动的产量、耗时与目标见「拾荒者劳动」「伐木工劳动」
  - 与**商业建筑雇员**区分：自由职业**不**绑定建筑上岗窗口
  - 产出先入角色库存，与**早市**无直接绑定
  - 日内时段见 [time.md](time.md)「日内四时段」

### 拾荒者劳动

- **规则**：拾荒者在**灌木丛**（`Plant`，见场上灌木实例）上劳动 **30 游戏分钟**完成一次采集，产出 **5** 个**浆果**（标签 **【食物】**）；仅当该灌木 **growth ≥ 0.75** 时可作为目标；完成后该灌木 **growth 降低 0.5**（灌木**不**移除）。
- **说明**：
  - growth 取值范围 **0～1**，与现有植物序列化字段一致
  - 叙事锚点见 [beautiful-corners/berry-glut-career-dead-end.md](beautiful-corners/berry-glut-career-dead-end.md)
  - 灌木 **growth** 自然恢复速率实现期配置

### 伐木工劳动

- **规则**：伐木工对场上**橡树**劳动 **2 游戏小时**完成一次砍伐，产出 **10** 个**原木**；完成后该树**彻底摧毁**（占格清场，实例移除）。
- **说明**：
  - **原木**为具体资源品种；标签与下游用途（建材等）实现期配置
  - 目标选取、无可用树木时的行为实现期定

### 日常转职

- **规则**：每个**游戏日** **0:00** 批处理（**市价更新之后**，见 [time.md](time.md)「游戏日批处理顺序」），每名场内角色（**含受雇者**）进行一次转职判定：对全部候选**自由职业**代入 [career-change-willingness-calculator.md](career-change-willingness-calculator.md)（分数模式）得转职权重，再按 [labor-benefit.md](labor-benefit.md)「转职抽取」执行（含**不转职**空白权重）。
- **说明**：
  - **自由职业**者：命中某自由职业则互转；命中空白则不转职
  - **受雇者**：当前职业为雇佣职业名（**不算**自由职业）；判定仍针对各**自由职业**候选；命中某自由职业则**先解除雇佣**（走离职薪酬结算），再转为该自由职业；命中空白则**留任**原雇佣岗
  - 候选不含雇佣职业；入职雇佣走「雇佣选人」
  - 转职与土地、占格无关
  - 空白权重补足至 100、命中空白则不转职：见 [labor-benefit.md](labor-benefit.md)「转职抽取」

### 雇佣职业离职

- **规则**：角色**不再需要**当前雇佣岗位时（含**被解雇**），**雇佣关系结束瞬间**角色**无职业**；随即对满足**任职条件**的全部候选自由职业调用转职意愿计算器（分数模式），再按 [labor-benefit.md](labor-benefit.md)「转职抽取」**离职分支**加权抽选，**必得**一门自由职业；同时**清除**「刚刚转职」标记。
- **说明**：
  - 触发时机含岗位撤销、**建筑竣工瞬间解雇建筑工**等；其余场景尚未穷举
  - 判定时当前劳动获益按 **0** 计；计算器对每名**可选**候选保证权重 **> 0**，见 [career-change-willingness-calculator.md](career-change-willingness-calculator.md)「雇佣离职转自由职业」
  - 不满足任职条件的自由职业**不进入**候选（示例：伐木工需**强壮**）

### 刚刚转职

- **规则**：角色每次**成功转职**（含自由职业互转、入职雇佣职业）后进入「刚刚转职」状态，持续 **7 个游戏日**；作为 [career-change-willingness-calculator.md](career-change-willingness-calculator.md) 的**负面因素**；在**被解雇**（雇佣岗位结束）时**立即清除**。
- **说明**：
  - 负面强度自转职当日起在 7 日内**逐渐递减**，第 7 日结束后归零（具体得分曲线与数值实现期调试）
  - 游戏日定义见 [overview.md](overview.md) 时间系统

### 劳动获益

- **规则**：角色职业经济获益的统一概念为**劳动获益**；生产类职业按**产出市值**（完成时市价）计量，雇佣类职业按**佣金**计量；跨职业比较规则见 [labor-benefit.md](labor-benefit.md)。

### 雇佣佣金与日薪底价

- **规则**：单角色接受某一雇佣岗位所需的**日薪底价**，由 [career-change-willingness-calculator.md](career-change-willingness-calculator.md)（议价模式）反推使总得分 **== 0** 的金额，非独立定价表；成交时 **协定日薪** = min(日薪底价, **日薪上限**)，见「协定日薪上限」。
- **说明**：
  - 支付方随场景而定（领主、建造方角色、建筑实例等），见 [economy.md](economy.md)
  - 与自由职业互转无关
  - **雇佣存续期间协定日薪锁定**，不随每日重算底价或上限；新雇佣关系须重新走「雇佣选人」并重新锁定

### 协定日薪上限

- **规则**：**协定日薪**不得超过雇主**经济单位**的 **日薪上限**（见 [economy.md](economy.md)「雇员与协定日薪上限」）：**日尺度获益** × **2** ÷ **满员岗位数**。
- **说明**：
  - 雇主为**建筑实例**或**角色**（示例：建造责任方雇**建筑工**）时同一公式
  - 收支事件口径与 [open-decisions.md](open-decisions.md) D13 联动

### 角色特征

- **规则**：角色拥有若干**特征**（如**识字**、**强壮**）；用于雇佣岗位**任职条件**判定，并在角色详情中展示。
- **说明**：
  - 特征列表与获取方式实现期配置；与职业、转职独立
  - 任职条件示例见「岗位任职条件」

### 岗位任职条件

- **规则**：雇佣岗位与**自由职业**均可配置**任职条件**；角色须满足该职业/岗位全部条件方可**上岗**或纳入对应**转职候选**。
- **说明**：
  - 示例：某雇佣岗要求**识字**；**伐木工**要求**强壮**；**拾荒者**首版无额外条件
  - 雇佣选人：底价只反映意愿，能否上岗由任职条件判定
  - 自由职业转职：不满足条件的职业**不参与**计算器与抽取池

### 角色详情

- **规则**：玩家**点击场内角色**打开**角色详情**面板（无独立劳动获益界面）；展示**姓名**、**当前职业**、**特征**、**劳动获益**。
- **说明**：
  - **劳动获益**展示该角色**最近一个游戏月**的**平均日劳动获益**（计量口径见 [labor-benefit.md](labor-benefit.md)「按职业类型的计量」）；一游戏月 = 7 游戏日，见 [overview.md](overview.md)
  - 样本不足整月时，以已有游戏日平均；无样本时显示占位（实现期定文案）
  - 不展示「自己雇佣自己」等雇佣内部口径，见「雇佣选人」

### 雇佣选人

- **规则**：需要填补某雇佣岗位时，对场内**每一名角色**（**含发起雇佣者本人**）求该岗位日薪底价，选用**满足任职条件且工资最低**者（须雇主支付得起）。细节见 [career-change-willingness-calculator.md](career-change-willingness-calculator.md)「雇佣选人」。
- **说明**：
  - **允许挖墙脚**：候选人**可以**正受他人雇佣；成交后**立即**结束其原雇佣关系，转入新岗位
  - 被挖走一方的**空岗立即**再次发起「雇佣选人」填补（同日流程内接续，不等待下一游戏日）
  - 自己雇自己用于收入统计；**玩家 UI 不展示「自己雇佣自己」**
  - 建筑工场景见「雇佣建筑工」；选人时以 min(底价, **日薪上限**) 比价，见「协定日薪上限」
  - 稀缺任职条件人才被多雇主争抢为**预期**行为，上限约束见「协定日薪上限」

### 雇佣结束与再雇

- **规则**：雇员因游戏机制结束当前岗位（含被解雇、施工竣工、岗位撤销、日常转职离职等）后，原雇主**可以**再次发起「雇佣选人」填补该岗。
- **说明**：
  - 再雇须重新议价选人并锁定新协定日薪，不沿用上一任薪酬
  - **挖墙脚**导致的空岗按「雇佣选人」**立即**再雇，见上节

### 建筑工与施工

- **规则**：**建筑工**为**雇佣职业**；任何建筑的**施工完成**须雇建筑工**转职上岗**执行，其它角色不得独自将工地从「待施工」变为竣工建筑。
- **说明**：
  - 占地、购地审批、购置占格、地基与填料等由建造责任方完成，见 [structures.md](structures.md)「建造施工流程」
  - 上岗即转职为建筑工；**建筑竣工瞬间**解雇该雇员，见「雇佣建筑工」

### 雇佣建筑工

- **规则**：工地材料填满后，建造责任方按「雇佣选人」（岗位=建筑工）选人上岗；若本人为**满足任职条件且工资最低**者则**自己雇佣自己**。受雇者转职为建筑工；**竣工瞬间**即解雇。若当场**雇不到人**，隔**一段时间**自动**重试**选人，直至上岗或工地取消。
- **说明**：
  - 选人走 [career-change-willingness-calculator.md](career-change-willingness-calculator.md) 议价模式；薪酬按「雇员薪酬结算」，协定日薪锁定至解雇
  - 竣工解雇后走「雇佣职业离职」转职流程
  - 允许挖墙脚（见「雇佣选人」）；工被挖走后原工地暂停施工，由原雇主按上款重试
  - **建筑工**受雇期间**仅服务一处**工地，不并行施工多栋建筑（见 [structures.md](structures.md)「建造施工流程」）

### 雇员薪酬结算

- **规则**：雇员薪酬自**入职时刻**起算；**每个游戏日**于 **0:00** 批处理结算一次（为当日批处理**第一项**，见 [time.md](time.md)「游戏日批处理顺序」）；**离职时**再结算一次未结清部分。不足一整游戏日的时段按**比例**折算日薪。
- **说明**：
  - 游戏日长度与 [overview.md](overview.md) 时间系统一致（`all_days` 的整数日为界，一日 = 游戏 24 小时）
  - **按比例示例**：
    - 入职当日：自入职时刻至**当日结束**（下一游戏日 0 点）的时长 / 1 游戏日 × 日薪
    - 离职当日：自**当日 0 点**至离职时刻的时长 / 1 游戏日 × 日薪（若入职与离职在同一游戏日内，则为入职至离职的时长 / 1 游戏日 × 日薪）
  - 结算按**协定日薪**（入职时锁定）折算，见「雇佣佣金与日薪底价」
  - **欠薪**：雇主无法支付应付薪酬时，**立即解除**雇佣关系，见 [structures.md](structures.md)「工地异常（欠薪与死亡）」
