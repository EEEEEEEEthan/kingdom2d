# 角色 / 职业

## 已定决策

### 职业分类

- **状态**：已定
- **规则**：角色拥有职业；职业分「自由职业」与「雇佣职业」两类。
- **说明**：
  - 两类职业的具体列表尚未定义
  - 同一角色是否可同时拥有两类、或互斥，尚未确定

### 自由职业转职

- **状态**：已定
- **规则**：每个角色每天可尝试向另一个自由职业转职。
- **说明**：
  - 转职目标限于自由职业
  - 转职是否成功、每日尝试次数上限等细节尚未确定

### 转职权重计算器

- **状态**：已定
- **规则**：转职依据由计算器得出权重；因素均为正向（如收入更高、职业更体面等）。计算器先得出**不含金钱**的权重，再反推使总权重 > 0 所需的最低金额。
- **说明**：
  - 非金钱因素汇总为「除钱以外的权重」
  - 金钱作为补偿项，补足非金钱权重为负时的缺口
  - 具体因素列表与权重公式尚未确定

### 雇佣佣金

- **状态**：已定
- **规则**：上述「使权重 > 0 的最低金额」即为雇佣职业的佣金依据。
- **说明**：
  - 佣金由转职权重计算器导出，非独立定价
  - 佣金支付方（通常为领主）与支付周期尚未确定
  - 与经济系统的货币流通衔接，见 [economy.md](economy.md)
