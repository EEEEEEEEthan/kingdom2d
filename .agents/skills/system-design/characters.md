# 角色 / 职业

### 职业分类

- **规则**：角色拥有职业；职业分「自由职业」与「雇佣职业」两类。
- **说明**：
  - 两类职业的具体列表尚未全部定义；**建筑工**为已确认的**雇佣职业**（见「建筑工与施工」）
  - 同一角色是否可同时拥有两类、或互斥，尚未确定

### 自由职业转职

- **规则**：每个**游戏日**，每名**自由职业**角色进行一次转职判定：对全部候选自由职业代入 [career-change-calculator.md](career-change-calculator.md)（分数模式）得转职权重，再按 [labor-benefit.md](labor-benefit.md)「转职抽取」执行（含**不转职**空白权重）。
- **说明**：
  - 候选不含雇佣职业；上岗走「雇佣选人」
  - 转职与土地、占格无关
  - 空白权重补足至 100、命中空白则不转职：见 [labor-benefit.md](labor-benefit.md)「转职抽取」

### 雇佣职业离职

- **规则**：角色**不再需要**当前雇佣岗位时（含**被解雇**），同样经转职计算器（分数模式）列举各自由职业权重，再按「转职抽取」执行，但**不设不转职空白**；同时**清除**「刚刚转职」标记。
- **说明**：
  - 触发时机含岗位撤销、**建筑竣工瞬间解雇建筑工**等；其余场景尚未穷举
  - 判定时当前劳动获益按 **0** 计；候选权重均 ≤ 0 时**不转职**，见 [labor-benefit.md](labor-benefit.md)「转职抽取」

### 刚刚转职

- **规则**：角色每次**成功转职**（含自由职业互转、入职雇佣职业）后带上「刚刚转职」标记；作为 [career-change-calculator.md](career-change-calculator.md) 的**负面因素**；在**被解雇**（雇佣岗位结束）时**清除**。
- **说明**：
  - 标记持续时长等：见 [open-decisions.md](open-decisions.md) **X3**

### 劳动获益

- **规则**：角色职业经济获益的统一概念为**劳动获益**；生产类职业按**产出市值**（完成时市价）计量，雇佣类职业按**佣金**计量；跨职业比较规则见 [labor-benefit.md](labor-benefit.md)。

### 雇佣佣金与日薪底价

- **规则**：单角色接受某一雇佣岗位所需的**日薪底价**，由 [career-change-calculator.md](career-change-calculator.md)（议价模式）反推使总得分 **== 0** 的金额，非独立定价表；成交时写入该次雇佣的**协定日薪**。
- **说明**：
  - 支付方随场景而定（领主、建造方角色等），见 [economy.md](economy.md)
  - 与自由职业互转无关
  - **雇佣存续期间协定日薪锁定**，不随每日重算底价；新雇佣关系须重新走「雇佣选人」并重新锁定

### 雇佣选人

- **规则**：需要填补某雇佣岗位时，对场内**每一名角色**（**含发起雇佣者本人**）求该岗位日薪底价，选用**底价最低**者；雇主须支付得起方能成交。细节见 [career-change-calculator.md](career-change-calculator.md)「雇佣选人」。
- **说明**：
  - **允许挖墙脚**：候选人**可以**正受他人雇佣；成交后结束其原雇佣关系，转入新岗位
  - 自己雇自己用于收入统计；**玩家 UI 不展示「自己雇佣自己」**
  - 建筑工场景见「雇佣建筑工」

### 雇佣结束与再雇

- **规则**：雇员因游戏机制结束当前岗位（含被解雇、施工竣工、岗位撤销等）后，原雇主**可以**再次发起「雇佣选人」填补该岗。
- **说明**：
  - 再雇须重新议价选人并锁定新协定日薪，不沿用上一任薪酬
  - 挖墙脚导致的前任雇主岗位空缺，同样可走再雇流程

### 建筑工与施工

- **规则**：**建筑工**为**雇佣职业**；任何建筑的**施工完成**须雇建筑工**转职上岗**执行，其它角色不得独自将工地从「待施工」变为竣工建筑。
- **说明**：
  - 占地、购地审批、购置占格、地基与填料等由建造责任方完成，见 [structures.md](structures.md)「建造施工流程」
  - 上岗即转职为建筑工；**建筑竣工瞬间**解雇该雇员，见「雇佣建筑工」

### 雇佣建筑工

- **规则**：工地材料填满后，建造责任方对场内**每一名角色**按「雇佣选人」（岗位=建筑工）求日薪底价，选用**最低**者上岗；若本人最低则**自己雇佣自己**。受雇者转职为建筑工；**竣工瞬间**即解雇。
- **说明**：
  - 选人走 [career-change-calculator.md](career-change-calculator.md) 议价模式；薪酬按「雇员薪酬结算」，协定日薪锁定至解雇
  - 竣工解雇后走「雇佣职业离职」转职流程
  - 允许挖墙脚（见「雇佣选人」）

### 雇员薪酬结算

- **规则**：雇员薪酬自**入职时刻**起算；**每个游戏日**结算一次；**离职时**再结算一次未结清部分。不足一整游戏日的时段按**比例**折算日薪。
- **说明**：
  - 游戏日长度与 [overview.md](overview.md) 时间系统一致（`all_days` 的整数日为界，一日 = 游戏 24 小时）
  - **按比例示例**：
    - 入职当日：自入职时刻至**当日结束**（下一游戏日 0 点）的时长 / 1 游戏日 × 日薪
    - 离职当日：自**当日 0 点**至离职时刻的时长 / 1 游戏日 × 日薪（若入职与离职在同一游戏日内，则为入职至离职的时长 / 1 游戏日 × 日薪）
  - 结算按**协定日薪**（入职时锁定）折算，见「雇佣佣金与日薪底价」
- **开放问题**：薪酬结算时刻（午夜/早市，随 `GameTime` 阶段定）；欠薪/罢工（P2）
