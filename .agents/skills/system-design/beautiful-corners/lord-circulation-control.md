# 最美角落：领主掌控流通与通胀

> 要让玩家看见的瞬间：**领主握着场内大部分货币，却不在估值样本里**——流通侧货币稀薄，物价难涨；领主选择在早市**撒钱收购**或**只进不出**，就能**加热或压制**场内通胀，而不只是旁观中位数自愈。

## 场景配置（示例）

- 开局 **二八分配**：领主 **8000**、全场角色合计 **2000**（见 [economy.md](../economy.md)「开局货币分配」）
- **流通货币**统计**不含**领主钱包；个人估值公式中的持有现金因子主要由角色与旅行商人贡献
- 领主长期**只收税、不消费** → 场内流通货币**持续偏紧** → 乘性估值因子中「持币」侧对多数人**偏弱** → **通胀压力弱**

## 地图与经济现状

- 角色侧现金少，早市购买力有限；**市价**对供给侧过剩（如浆果堆积）更敏感，对领主侧需求注入**不敏感**（领主不进中位数样本）
- 与 [berry-glut-career-dead-end.md](berry-glut-career-dead-end.md) 可叠加：僵局时若领主仍 hoard，流通侧更难自稳

## 玩家（领主）可见的杠杆

1. **只进不出**：税、购地收入回流领主钱包 → 流通货币**缩水** → 物价**难涨**（刻意设计的调控手段）
2. **主动放币**：早市收购、向角色支付薪酬（若扩展领主直接雇佣）、低价抛售库存物资等 → 向场内**注入流通货币** → 提振需求侧与中位价
3. **审批与建设**：间接改变就业与品种结构（见浆果僵局角落），与货币杠杆**并用**

## 要展现的设计要点

- 领主 **80%** 持币且**不计入流通**，不是疏漏，而是给玩家**货币政策**手柄： hoard = 偏通缩环境； spend = 通胀油门
- **领主不参与**商品估值中位数样本，与「领主可交易但不操纵中位数公式」并存——影响物价主要靠**实物与货币吞吐**，非刷估值
- 系统须允许领主在早市等渠道**实质性参与买卖**（见 [economy.md](../economy.md)「早市」），否则杠杆只存在于叙事
