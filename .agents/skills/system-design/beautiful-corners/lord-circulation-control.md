# 最美角落：领主掌控流通与通胀

> 要让玩家看见的瞬间：**领主握着场内大部分货币，却不在估值样本里**——流通侧货币稀薄，物价难涨；领主选择**只进不出**（税、购地）或**主动释货**（调低库存阈值），就能**压制或提振**场内供需，而不只是旁观中位数自愈。

## 场景配置（示例）

- 开局 **二八分配**：领主 **8000**、全场角色合计 **2000**（见 [economy.md](../economy.md)「开局货币分配」）
- **流通货币**统计**不含**领主钱包；个人估值公式中的持有现金因子主要由角色与旅行商人贡献
- 领主为场上**红色小人**，**不参与**早市买卖与生产劳动（见 [economy.md](../economy.md)「领主（玩家角色）」）
- 领主长期**只收税、不释货** → 场内流通货币**持续偏紧** → 乘性估值因子中「持币」侧对多数人**偏弱** → **通胀压力弱**

## 地图与经济现状

- 角色侧现金少，早市购买力有限；**市价**对供给侧过剩（如浆果堆积）更敏感，对领主侧需求注入**不敏感**（领主不进中位数样本）
- 与 [berry-glut-career-dead-end.md](berry-glut-career-dead-end.md) 可叠加：僵局时若领主仍 hoard 且不调阈值，流通侧更难自稳

## 玩家（领主）可见的杠杆

1. **只进不出**：税、购地收入回流领主钱包 → 流通货币**缩水** → 物价**难涨**（刻意设计的调控手段）
2. **库存阈值**：调低名下或全场建筑**库存阈值** → 盈余更易**铺面代摊 / 店内成交** → 实物与服务释入流通、制造需求侧压力（见 [commerce.md](../commerce.md)「建筑库存阈值」）
3. **审批与建设**：间接改变就业与品种结构（见浆果僵局角落），与货币/库存杠杆**并用**
4. **市场交易**（未决）：领主如何与角色直接买卖见 [open-decisions.md](../open-decisions.md) D21

## 要展现的设计要点

- 领主 **80%** 持币且**不计入流通**，不是疏漏，而是给玩家**货币政策**手柄： hoard = 偏通缩环境；释货/阈值 = 供给侧油门
- **领主不参与**商品估值中位数样本，与「不通过刷估值操纵市价」并存——影响物价靠**实物吞吐**与**流通货币规模**，非领主亲自摆摊
- 破局须依赖**已定**手段（审批、阈值、税收）；**早市亲自买卖**不在首版规则内
