# 最美角落：多格铺位的组合购地

> 要让玩家看见的瞬间：**一间长条作坊横跨三格**——得先买下别人格上的铺子拆掉，再向领主买断旁边一块空地，领主在一条审批里看清整单方案后点头或整单作废。

## 场景配置（示例）

- 某角色要建**占地跨多格**的建筑（示例：长条作坊占 **3 格**）
- 比选 Footprint 后，最省方案：**1 格**上已有他人建筑须**购置拆毁**，**1 格**为空地须**向领主购地**，余下占格由已持有或购地/购置后凑齐（本例：「买 1 座别人的 + 买 1 块空地」）

## 玩家可见的流程

**审批**：因含空地购地，向领主发起**一条**待办，例如：

> {角色}拟在{格 A、格 B…}建造{类型}：格 B 须购地，格 A 须向{卖方}购置{现建筑}后拆除

**领主审批**（见 [structures.md](../structures.md)「领主审批流程」）：

1. 打开详情 → **异步检查**（仍有购买意愿 & 买得起）；不过 → 提示**请求已过期**
2. 拒绝 → 结束
3. 同意 → 再 **异步检查**；不过 → **请求已过期**
4. **结算交易**（购地 + 购置拆毁等整单原子完成）→ 随后在 Footprint 上按**建造施工流程**推进

## 要展现的设计要点

- 多格建筑不是「一格一格分别审批」，而是**一条整单**概括组合方案
- 购置格**不单独**再开第二条购地外审批，但**纳入**同一整单
- 领主点同意时校验的是「这单组合**现在**还能不能做成」，而非只批准空地那一格
- 系统须支持：Footprint 比选、组合方案待办、打开/同意各一次异步检查、结算原子完成
