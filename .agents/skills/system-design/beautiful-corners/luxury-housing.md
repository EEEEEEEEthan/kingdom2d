# 最美角落：奢侈住房的稀缺选址

> 要让玩家看见的瞬间：**攒够钱却择址艰难**——奢侈住房占地宽，全图仅两处 Footprint 够格，且无论怎样比选，最优方案都得「买下别人的格 + 向领主买断旁边空地」；领主在一条审批里看清整单后点头或作废，角色才能在「最美角落」建起自己的家。

## 场景配置（示例）

- 某角色原住简陋住房，积蓄后欲迁入**奢侈住房**
- 奢侈住房配置高**住房等级**，且 Footprint 较宽（示例：入口格 + **左 1** + **右 1**，共 **3 格**）
- 选址须达到足够**服务等级**（示例：以目标格为中心 **15 格**内须同时存在**酒馆**与**铁匠铺**；邻域由地图现状判定，非买方自带）

## 地图现状

- 全图仅 **2 个** Footprint 落点满足上述选址
- 两处落点的 **3 格占格构成相同**：**2 格已占** + **1 格空地**（故任意最优组合方案**必含**至少一格须向领主购地）
- 示例落点 A（本角落假设总成本更低）：**空地**｜**澡堂**（入口）｜**木匠铺**
- 示例落点 B：**空地**｜**澡堂**（入口）｜**铁匠铺**（或另一组已占组合；两落点共享周边酒馆/铁匠铺，戏剧在占格组合与估值差异）

## 玩家可见的流程

1. 角色比选两处 Footprint 落点，分别估算组合成本（**购地价** + 各**购置格**商业估值）；落点 A 更省，且角色**支付得起**整单
2. 对落点 A 上须购置的格（澡堂、木匠铺）**询价** → 按该建筑实例当日最终估值（创值 + 类型保底 + 竣工保护加成，若适用）
3. 因方案含空地购地，向领主发起**一条**组合待办，例如：

   > {角色}拟在{格左、澡堂格、木匠铺格}建造奢侈住房：格左须购地，澡堂格须向{卖方}购置澡堂后拆除，木匠铺格须向{卖方}购置木匠铺后拆除

4. **领主审批**（见 [structures.md](../structures.md)「领主审批流程」）：
   - 打开详情 → **异步检查**；不过 → **请求已过期**
   - 拒绝 → 结束
   - 同意 → 再 **异步检查**；不过 → **请求已过期**
   - **结算交易**（购地 + 购置拆毁等整单原子完成）
5. 随后在 Footprint 上按**建造施工流程**推进（地基、填料、雇建筑工）→ 竣工奢侈住房

## 要展现的设计要点

- 奢侈条件由**周边已有**酒馆/铁匠铺满足，买方不能「自带」设施
- **宽 Footprint** 使「纯购置」或「纯购地」均不可能一次凑齐；比选后仍**必走组合方案**
- 买方买的是稀缺区位上的**占格权**，不是澡堂/木匠铺的**功能**
- 两落点同享一套周边设施时，戏剧张力在**不同占格组合、不同卖方实例**之间的比价
- 系统须走通全流程：邻域选址、多格 Footprint 比选、购置询价、购地、组合整单审批、拆后自建、雇建筑工竣工
