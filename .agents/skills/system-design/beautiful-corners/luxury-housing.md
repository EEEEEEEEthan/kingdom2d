# 最美角落：奢侈住房的稀缺选址

> 要让玩家看见的瞬间：**攒够钱却找不到空地**——全图仅两格配得上奢侈住房，只好拆掉别人的澡堂，在「最美角落」上建起自己的家。

## 场景配置（示例）

- 某角色原住简陋住房，积蓄后欲迁入**奢侈住房**
- 奢侈住房配置高**住房等级**；选址须达到足够**服务等级**（示例：以目标格为中心 **15 格**内须同时存在**酒馆**与**铁匠铺**，对应服务等级 ≥ 奢侈住房所需；邻域由地图现状判定，非买方自带）

## 地图现状

- 全图仅 **2 格**满足上述选址
- 两格皆已被占：**木匠铺**、**澡堂**（均为工作场所）
- 无合格空地 → 走 [structures.md](../structures.md)「无空地则购置占格权」

## 玩家可见的流程

1. 角色对两格各**询价** → 各格按**现有商业建筑**（澡堂 / 木匠铺）近一年净收入估值（本角落假设澡堂格更低）
2. 澡堂格报价低于木匠铺格，且角色**支付得起**澡堂价
3. 在可成交且支付得起的候选格中取**最低价** → 选中澡堂格
4. **付价** → **拆掉澡堂** → 进入**建造施工流程**（地基、填料、雇建筑工）→ 竣工奢侈住房

## 要展现的设计要点

- 奢侈条件由**周边已有**酒馆/铁匠铺满足，买方不能「自带」设施
- 买方买的是「稀缺区位上的占格权」，不是澡堂或木匠铺的**功能**
- 两格同享同一套周边设施时，戏剧张力在**不同卖方、不同实例**之间的比价
- 系统须支持：邻域选址判定、多候选询价、支付能力校验、拆后自建全链
