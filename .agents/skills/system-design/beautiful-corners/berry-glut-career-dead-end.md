# 最美角落：浆果过剩与转职僵局

> 要让玩家看见的瞬间：**全员拾荒者（采浆果）把浆果估值采崩了**——中位价跌到采浆果几乎无利可图，转职意愿全体为负，没人去建铺、当雇工、开新供给；**领主**必须动用审批、购地、税收、早市规则等**手段**打破僵局，而不只是旁观数值自愈。

## 场景配置（示例）

- 场内多数角色为**拾荒者**自由职业；近几个游戏日**浆果**产量高、流通多，个人估值公式中乘性因子连降
- **浆果**当日 raw 中位价极低；平滑后**市价**仍持续走低
- 生产类**产出市值**（完成时市价 × 数量）随之萎缩 → [career-change-willingness-calculator.md](../career-change-willingness-calculator.md) 分数模式下，转职去其他职业的权重**全体 ≤ 0** 或极低

## 地图与经济现状

- 食物标签仍有人需要，但**浆果**相对**苹果**等替代品估值塌陷（品种分账）
- 尚无（或不足）**铁匠铺 / 酒馆**等改变服务等级与就业结构的建筑
- 角色有钱也**不愿**租更好床或自建，若转职无利且生活尚可通过标签内调剂苟住

## 玩家（领主）可见的困境

1. 早市与摆摊：**浆果**堆积、市价低，卖浆果换不到钱
2. 角色详情：劳动获益下降；长期无人转职去「体面」或高获益职业
3. 待办稀少：无人申请购地建商业，邻域服务等级上不去
4. 若领主**只进不出**（80% 货币），流通侧更加缺乏调节杠杆

## 领主可动用的手段（示例，非穷举）

- **审批购地 / 组合方案**：主动批准关键格上的**商业**或**多格作坊**，打破「没人愿建」——见 [multi-tile-workshop.md](multi-tile-workshop.md)
- **税收与建筑运营**：通过 [commerce.md](../commerce.md) 日税与床位租金，改变持有**住房 + 商业**的相对收益（间接影响估值公式输入）
- **库存阈值**：调低建筑阈值促使过剩品种释入早市代摊/流通，间接消化浆果（见 [commerce.md](../commerce.md)「建筑库存阈值」、[economy.md](../economy.md)「领主（玩家角色）」）
- **领主市场交易**（未决，见 [open-decisions.md](../open-decisions.md) D21）：首版领主**不参与**早市买卖
- **旅行商人**：若入境携带**非浆果**需求或货物，可短暂抬升其他品种中位价、分流就业（出现频率与池子为配置）

## 要展现的设计要点

- **市价 = 众人估值中位数**时，同质劳动扎堆会导致**价格内卷**——这是**预期行为**，不是 bug
- **转职意愿**与**产出市值**挂钩时，低市价 → 低获益 → 低转职权重，形成**僵局**
- **破局责任在领主侧**（玩家），系统须提供购地审批、税收、建筑类型差异等**可操作策略**，而非隐藏均衡器
- 与 [luxury-housing.md](luxury-housing.md) 互补：彼处是「有钱难择址」；此处是「有价无业、无业难建」
