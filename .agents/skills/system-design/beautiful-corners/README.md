# 最美角落

> **叙事锚点**：用具体、可想象的游戏瞬间检验系统设计。规则文档（如 [structures.md](../structures.md)）记**机制**；本目录记**要让玩家看见的故事**。

## 设计原则

- **状态**：已定
- **规则**：系统设计以本目录中的**最美角落**为检验标准；各子文档机制须能支撑并**展现**这些场景，而非仅逻辑自洽。
- **说明**：
  - 每个最美角落是独立叙事 vignette：角色、动机、地图现状、关键抉择与结局
  - 角落内的建筑名、格数、邻域半径等为**示例配置**，非全局平衡定案；机制冲突时以各子文档规则为准
  - 新增系统或改机制时，对照本目录：能否走通至少一个角落？若不能，须补机制或修订角落并获确认
  - 新角落先入本目录；其中沉淀的**可复用规则**经确认后写入对应子文档
