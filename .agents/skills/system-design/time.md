# 时间与日内时段

> 游戏日历见 [overview.md](overview.md)。本节定义**一日内**阶段划分及与商业上岗的关系。

### 游戏日

- **规则**：**1 游戏日** = 游戏内 **24 小时**；与 [characters.md](characters.md)「雇员薪酬结算」、 [economy.md](economy.md)「近一年」统计窗口一致。
- **说明**：
  - 7 游戏日 = 1 游戏月；12 游戏月 = 1 游戏年（见 [overview.md](overview.md)）

### 日内四时段

- **规则**：每个游戏日按固定顺序划分为四时段：**早市 → 工作 → 休息 → 睡眠**。
- **说明**：
  - 各时段在游戏日内的**起止时刻与时长**由配置表给出（实现期定具体小时数）
  - 时段边界为闭开或闭区间由实现统一约定；跨时段行为以「上岗窗口」配置为准（见 [commerce.md](commerce.md)「上岗窗口」）

### 休息时段私人事务

- **规则**：**休息**时段内，角色处理**私人事务**：建造工地的**填料**、向名下建筑**注资/提走分红**（见 [commerce.md](commerce.md)「运营支出与运营储备」）、及其他不涉及上岗窗口的个人行为。
- **说明**：
  - **生活水平**升级进度条按**游戏日**结算，不限于休息段；见 [needs.md](needs.md)「升级进度条」
  - 住房建造日更评估与领主待办发起可在日更时刻完成；填料等须在休息段执行

### 标准上岗时长

- **规则**：开放**上岗窗口**的建筑类型，其雇员共用同一 **标准上岗时长**（游戏小时数，配置常量）；任意类型的**上岗窗口**时长**必须等于**标准上岗时长。
- **说明**：
  - **公平性**：各商业岗位每日劳动时间相等；**协定日薪**对应该标准时长内的岗位报酬（见 [characters.md](characters.md)「雇佣佣金与日薪底价」）
  - **不纳入**本约束：自由职业劳动、**建筑工**施工上岗（项目制短岗）、领主等
  - 上岗窗口可**跨越**日内时段边界（示例：酒馆窗口从「工作」末段起始，延续入「休息」初段）
