# 商品估值计算器

> 每名主体对**具体资源品种**给出**个人估值**（货币金额）；全场**中位数**经平滑后形成**当日市价**。与 [career-change-willingness-calculator.md](career-change-willingness-calculator.md)、[rent-willingness-calculator.md](rent-willingness-calculator.md) 同属「主体意愿 → 聚合价格」族。市价用途见 [economy.md](economy.md)「价格形成」。

### 核心机制

- **规则**：**每个游戏日**、每个**具体品种**，对**计入样本的全部主体**（见下）各算一笔**个人估值**；取**中位数**为当日该品种的** raw 中位价**，再与**上日市价**平滑得到**当日市价**。
- **说明**：
  - **领主（玩家）不参与**个人估值与中位数样本
  - **计入样本**：场内**常驻角色** + 在境**旅行商人**（与 [economy.md](economy.md)「流通货币」主体范围一致，不含领主）
  - **不设品种基准价**；公式由加性项与乘性项组合，实现期可调整，须保证输出恒为**正数**（无零/负估值）
  - 钱多者的极端估值由**中位数**自然剃除

### 估值公式（v0 · 暂定）

- **规则**：个人对某品种的估值由**加性因素**与**乘性因素**组合；v0 **暂定**沿用下列示例结构（系数与组合顺序实现期调试）：
- **说明**：
  - **加性示例**：持有现金（示例：我有 1000 现金 → **+1000**）
  - **乘性示例**（示例：苹果）：
    - 该品种产量很高 → **×0.1**
    - 该品种流通很多 → **×0.1**
    - 该品种需求量很大 → **×1.1**
    - 角色很饿 → **×2.0**
    - 角色爱吃该品种 → **×1.1**
  - 上列组合示例结果约为 **22**（非平衡定案，仅说明因子类型）
  - 产量、流通、需求等取**当日快照**（如全场该品种持有/产出/标签需求等）

### 因素

- **规则**：估值因素按品种与角色状态配置（加性 / 乘性）；具体得分函数与权重**实现期调试**。
- **说明**：
  - 因素方向示例：现金↑ → 估值↑；产量↑、流通↑ → 估值↓；需求↑、饥饿↑、偏好↑ → 估值↑
  - 旅行商人使用同一套计算器结构，输入改为其**特殊标签需求**与货物池（见 [economy.md](economy.md)「旅行商人」）

### 价格形成（与本计算器衔接）

- **规则**：见 [economy.md](economy.md)「价格形成」：**当日市价** = 对** raw 中位价**与**上日市价**做平滑（上日价**参与**计算）；于每日 **0:00** 批处理、**薪酬之后、早市之前**更新（见 [time.md](time.md)「游戏日批处理顺序」）。
- **说明**：
  - 早市成交、产出市值（[value-creation.md](value-creation.md)）、建造材料市价引用等，均使用**当日市价**
