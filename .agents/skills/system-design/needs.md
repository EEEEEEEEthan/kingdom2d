# 生活水平

> 角色生活动机的统一模型：阶梯式条件、进度条升降级、住房建造/租约与居住选择。经济预期库存见 [economy.md](economy.md)；建造流程见 [structures.md](structures.md)；床位租约见 [commerce.md](commerce.md)；租意愿见 [rent-willingness-calculator.md](rent-willingness-calculator.md)；休息时段见 [time.md](time.md)。

### 生活水平阶梯

- **规则**：每名角色拥有**生活水平等级**（非负整数，配置表定义各级条件）；各级条件全部满足后，通过**升级进度条**升至下一级并**解锁**该级对应的生活诉求（含更高**自有**住房目标）。
- **说明**：
  - 条件类型含**标签库存**（示例：【食物】储备若干天消耗量）与**实际住房等级**下限（见 [structures.md](structures.md)「住房等级与服务等级」）
  - 各级阈值由配置表给出（示例中的 2 天、3 天仅为举例，以配置为准）

### 升级进度条

- **规则**：设当前生活水平为 **n**；**升级进度条**按**游戏日**结算：若 **≤ n** 级的全部条件均满足，进度**增加**；若 **< n** 级中**任一**条件不满足，进度**减少**。进度**满**则升至 **n+1** 并重置为 **10%**；进度降至**负值**则降至 **n−1** 并重置为 **10%**。进度在 **7 个游戏日**内从 10% 涨至满（或从满降至 0，实现期统一速率曲线）。
- **说明**：
  - 10% 为升级/降级后的起始进度（暂定，实现期可调）
  - 进度条与**进行中的建造工地**独立；仅**建筑工欠薪**导致工地取消时与建造联动，见 [structures.md](structures.md)「工地异常（欠薪与死亡）」

### 住房条件与居住

- **规则**：生活水平中的住房条件以角色**当前居住地**的**实际住房等级**判定；**自有**（建筑主人占床或名下建筑）与**租约**（见 [commerce.md](commerce.md)「床位租约」）均可满足。
- **说明**：
  - 尚未满足首档住房条件前，角色**睡地板**（无惩罚露营）
  - 角色**始终居住**于其所选**单一**居住地：在**实际住房等级最高**的候选中择一（自有占床/租约床；同级 tie-break 实现期定）
  - **解锁自有住房诉求**只触发**自建** AI，不禁止同时**租床**过渡

### 住房需求：先租后建

- **规则**：当生活水平要求**实际住房等级**且角色**无**满足条件的**自有占床**时，**每个游戏日**按序：**(1) 寻租** → **(2) 若无合格租约则评估自建**。
- **说明**：
  - **寻租**：在**有空床**且**实际住房等级 ≥ 当前需求**的建筑中，对每床传入**挂牌日租**调用 [rent-willingness-calculator.md](rent-willingness-calculator.md)；仅 **租意愿 ≥ 0** 且角色**支付得起**当日租金的床位可租入；在可租入床中选**挂牌日租最低**者
  - **自建**：仅当**无任何**满足条件的租约时，才走「住房建造触发」
  - 有**建造中**自有工地时，仍可寻租过渡；见「租房与合租」

### 租房与合租

- **规则**：租约逻辑见 [commerce.md](commerce.md)「床位租约」「床位挂牌租金」；**续租**与**离店**由租意愿计算器日更判定。
- **说明**：
  - 用于弃房、清场、换房间隙、先租后建等**过渡**；同一建筑多床即**合租**
  - 建筑**占格清场**时租约终止，下一游戏日重走「住房需求：先租后建」

### 住房建造触发

- **规则**：当生活水平**解锁**某一档**自有住房**诉求（示例：朴素住房）后，且当日**寻租失败**（见「住房需求：先租后建」），角色**评估是否开建**：若该角色**已有**「建造中」工地（含待审批、地基、填料、待施工，不限建筑类型），**不**发起新建造。否则按 [structures.md](structures.md) **完整**选址与比选（Footprint、服务等级、购置、组合方案、当日市价、须购地格的**购地价**），若通过 [structures.md](structures.md)「**建造可负担判定**」则发起建造；**同一方案**已有领主待办在队时**不重复**发起。真正结算须待领主审批通过（见「领主审批流程」）；日更评估**不因**待办在队而视为不可负担。
- **说明**：
  - 每名角色**同一时间仅一处**建造中工地，见 [structures.md](structures.md)「建造施工流程」
  - 审批通过前仅评估与排队，不占格结算
  - 地基放置、填料、向建筑注资/分红等**私人事务**在**休息**时段处理，见 [time.md](time.md)「休息时段私人事务」
  - **雇佣建筑工**施工阶段可晚于首版实现；材料填满前的流程须先可跑通

### 换房与弃房

- **规则**：新自有住房**竣工**后，若其**实际住房等级**高于旧自有住房，角色**迁入新住房**（占床）并对旧住房执行**弃房**；若新住房**实际住房等级 ≤** 旧住房，对**新住房**执行**弃房**（不迁入），继续住旧住房。
- **说明**：
  - **弃房**：建筑实例**消失**，占格**土地归领主**，格变为**彻底空地**；**不退**购地价、**不**回购、**不**回收材料（见 [structures.md](structures.md)「占格清场」）；该建筑全部租约同步终止
  - 生活水平**降级**不取消已开工的住房建造；竣工后仍按上段规则比较实际等级并择居
