# 转职计算器

> 源于角色**转职**决策；现用于**雇佣议价、占格出售/回购**等「当事人愿不愿意」类决策。与 [building-valuation-calculator.md](building-valuation-calculator.md)（建筑估值计算器）分离：后者给出建筑**客观估值**，本计算器给出**临界成交价/日薪**。

## 已定决策

### 核心机制

- **状态**：已定
- **规则**：对一次决策先汇总**除金钱以外**的因素权重，再将**金钱**作为补偿项加入总权重；总权重由场景要求反解出临界金额。
- **说明**：
  - 非金钱因素示例：**劳动获益更高**（见 [labor-benefit.md](labor-benefit.md)）、职业更体面、仍在使用该建筑、区位稀缺、急用钱等；亦可引用 [building-valuation-calculator.md](building-valuation-calculator.md) 的**估值**（如重置成本参照）（完整列表尚未定义）
  - 因素方向与正负号按场景配置；转职场景曾约定因素均为「正向偏好」
  - 金钱项与总权重的函数形式（线性、分段）尚未确定
  - **不是**独立物价表；同一角色在不同场景下可得到不同临界金额

### 反解阈值：两种模式

- **状态**：已定
- **规则**：
  - **接受阈值（> 0）**：反推使总权重 **> 0** 的**最低金额**。表示「给到这个数，当事人才愿意接受」。
  - **无保留阈值（== 0）**：反推使总权重 **== 0** 的金额。表示「给到这个数，当事人无保留、无额外索价」。
- **说明**：
  - 若不存在有限金额能满足目标阈值（非金钱权重过强且金钱拉不平），视为该场景**无有效报价**（不可雇、不可成交等）

## 已定用途（按场景）

| 场景 | 文档 | 当事人 | 阈值 | 临界金额含义 |
|------|------|--------|------|----------------|
| 转职为雇佣职业 / 接受岗位日薪 | [characters.md](characters.md) | 被评估角色 | > 0 | **日薪底价**（雇佣佣金） |
| 雇佣建筑工（选最低价者） | [characters.md](characters.md) | 场内每名角色，目标岗位=建筑工 | > 0 | 各角色日薪底价；雇主取**最低** |
| 角色间购置占格（拆后自建） | [structures.md](structures.md) | 建筑主人（卖方） | == 0 | 该格**最终成交价** |
| 领主回购建筑收回土地 | [structures.md](structures.md) | 建筑主人（卖方） | == 0 | 回购成交价 |

## 调用约定（实现向）

- **输入（概念层）**：被评估角色、场景类型、场景上下文（如目标职业、交易建筑实例、买方身份等）
- **输出**：临界金额，或「无解」
- **比价**：建筑购置等流程中，买方对多候选格分别求卖方临界金额后比价，见 [structures.md](structures.md)「购置询价」
