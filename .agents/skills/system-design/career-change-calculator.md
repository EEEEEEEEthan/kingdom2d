# 转职计算器

> 用于**雇佣议价**（反推日薪底价）与**雇佣选人**（全场比价取最低）。自由职业转职的权重抽取见 [labor-benefit.md](labor-benefit.md)「转职权重 / 转职抽取」。占格购置/回购定价见 [structures.md](structures.md)。

## 已定决策

### 核心机制

- **状态**：已定
- **规则**：对一次决策先汇总**除金钱以外**的因素权重，再将**金钱**作为补偿项加入总权重；总权重由场景要求反解出临界金额。
- **说明**：
  - 非金钱因素示例（完整列表尚未定义）：劳动获益更高（相对当前职业与目标岗位）、职业更体面、急用钱等
  - 因素方向与正负号按场景配置
  - 金钱项与总权重的函数形式（线性、分段）尚未确定
  - **不是**独立物价表；同一角色在不同场景下可得到不同临界金额

### 反解阈值：两种模式

- **状态**：已定
- **规则**：
  - **接受阈值（> 0）**：反推使总权重 **> 0** 的**最低金额**。表示「给到这个数，当事人才愿意接受」。
  - **无保留阈值（== 0）**：反推使总权重 **== 0** 的金额。表示「给到这个数，当事人无保留、无额外索价」。
- **说明**：
  - 若不存在有限金额能满足目标阈值（非金钱权重过强且金钱拉不平），视为**无有效报价**（不可雇等）
  - 当前已定用途均为雇佣场景，使用**接受阈值（> 0）**；无保留阈值（== 0）机制保留，暂无已定场景

### 自由职业转职不使用本计算器

- **状态**：已定
- **规则**：自由职业互转及雇佣离职转自由职业，走 [labor-benefit.md](labor-benefit.md) 的**转职权重 / 转职抽取**；与金钱、本计算器无关。
- **说明**：
  - 转职与土地所有权、占格、建筑购置/回购无关
  - 成为雇佣职业走下方**雇佣选人**，不属于自由职业转职

### 雇佣选人

- **状态**：已定
- **规则**：需要某**雇佣岗位**时，对场内**每一名角色**（**含雇主本人**）代入本计算器，得到各自接受该岗位的**日薪底价**；在**有解**者中取底价**最低**者雇佣。
- **说明**：
  - 「转职为目标岗位」在此语境指**接受雇佣**为该岗位，非自由职业转职
  - **自己雇佣自己**允许，用于劳动获益/收入统计口径一致；**玩家 UI 不展示「自己雇佣自己」**字样（逻辑仍成立）
  - 若最低价者不可雇（它处约束等），次低者规则尚未确定

## 已定用途（按场景）

| 场景 | 文档 | 当事人 | 阈值 | 输出 |
|------|------|--------|------|------|
| 单角色接受雇佣岗位 | [characters.md](characters.md) | 被评估角色 | > 0 | **日薪底价** |
| 雇佣选人（含建筑工等） | [characters.md](characters.md) | 场内每名角色 | > 0 | 各角色日薪底价；取**最低**有解者 |

## 调用约定（实现向）

- **输入（概念层）**：被评估角色、场景类型、场景上下文（**目标岗位**等）
- **输出**：日薪底价，或「无解」
