# 角色创值

> **角色经济单位**的**创值**计量（统一创值模型见 [economy.md](economy.md)「创值」「生产行为记录」）。衡量角色从事当前职业所创造的经济价值；是跨职业比较、转职决策等系统的核心概念。与现金**收入**不同：自由职业创值可来自实物产出折算（完成时市价），雇佣职业创值来自**佣金**。

### 个体创值

- **规则**：每名角色**独立计算**自身创值；按当前职业类型，从生产行为记录与薪酬事件中聚合。
- **说明**：
  - **不是**现金流入全貌；自消、入库、未售出的产出仍可能计入（自由职业）
  - **不是** [building-valuation-calculator.md](building-valuation-calculator.md) 的建筑估值，亦非领主钱包或流通货币统计
  - 日常比较与计算器输入通常取**一个游戏日**尺度的创值（下称**日创值**），与 [characters.md](characters.md)「雇员薪酬结算」的日薪周期一致
  - **日创值** = 角色 **创值·最近 1 游戏日**（及月/年窗口的日均创值）；用于协定日薪上限的**日尺度创值**等，见 [economy.md](economy.md)「创值」「雇员与协定日薪上限」

### 按职业类型的计量

- **规则**：个体创值因职业类型而异，统一用下列两种方式之一计量：

| 职业类型 | 计量方式 | 计算 |
|----------|----------|------|
| **生产类自由职业**（如拾荒者、伐木工） | **产出市值** | 各次生产完成时，该次产出商品的 `数量 × **完成时刻**商品市价` |
| **雇佣类职业**（建筑工、商业雇员等） | **佣金** | 该岗位实发薪酬（日薪或雇佣关系下按比例折算的现金）；建筑自动产出不计入雇员创值 |

- **说明**：
  - 生产类自由职业不可仅用现金流入衡量（如自食无现金收入；短缺时采集类创值仍可能最高）
  - 商业建筑雇员为**雇佣类**计量（佣金），与建筑被动产出分离，见 [commerce.md](commerce.md)「建筑自动生产」
  - 产出市值：自消、入库、售出均计入；未产出部分不计；市价取**生产完成时刻**的**当日市价**（见 [goods-valuation-calculator.md](goods-valuation-calculator.md)、[economy.md](economy.md)「价格形成」）
  - 雇佣类创值即劳动换得的**佣金**（与 [characters.md](characters.md)「雇员薪酬结算」一致）
  - 每次生产完成均写入 [economy.md](economy.md)「生产行为记录」，保留一年

### 职业创值（中位数）

- **规则**：场内某**职业**的创值 = 该职业全部在场角色**个体创值**（同一聚合窗口）的**中位数**；该职业**人数为 0** 时，改用**全场全部角色**个体创值的中位数。
- **说明**：
  - 转职意愿计算器分数模式比较目标职业与当前职业的**职业创值**（见 [career-change-willingness-calculator.md](career-change-willingness-calculator.md)）
  - 聚合窗口与转职判定时刻一致，实现期约定（默认可对齐**日创值**）
  - 中位数降低极端个体对职业评价的拉动（对比算术平均）

### 角色详情展示

- **规则**：玩家可见的创值**仅**在 [characters.md](characters.md)「角色详情」中展示；即该角色 **创值·最近 1 游戏月**（7 游戏日内日创值算术平均）。
- **说明**：
  - 按角色**实际从事职业**逐日计量（转职、雇佣变更后分段计入），非职业表全局中位数
  - 与转职意愿计算器所用的**职业创值**可用不同窗口；意愿计算器窗口见上节「职业创值（中位数）」
  - 无独立创值调试面板

### 跨职业比较

- **规则**：比较两种职业的创值时，取各自**职业创值**（中位数）在同一货币尺度下比大小。
- **说明**：
  - 转职意愿计算器**分数模式**以目标职业与当前职业的**职业创值**比较为正面因素；**议价模式**无视创值比较，反推日薪底价见 [career-change-willingness-calculator.md](career-change-willingness-calculator.md)

### 转职抽取

- **规则**：
  - 转职意愿计算器（分数模式）为 **x** 个候选自由职业各输出一个**转职权重**；**≤ 0 丢弃**，**> 0** 入池。
  - **日常转职**（自由职业与受雇者，见 [characters.md](characters.md)「日常转职」）：每个游戏日 **0:00** 批处理一次（见 [time.md](time.md)「游戏日批处理顺序」）；**不转职空白权重** = `100 −` 池中各职业权重之和（不足 0 时按 0）；职业权重与空白权重合计 **100**，按权重随机抽取；**命中空白则不转职**（受雇者留任），命中某自由职业则转职（受雇者先解除雇佣）。
  - **雇佣职业离职**：仅对**满足任职条件**的候选自由职业计权重，**不设空白**；池中各权重 **> 0**（计算器保证，见 [career-change-willingness-calculator.md](career-change-willingness-calculator.md)「雇佣离职转自由职业」），加权抽取并**必转**一门自由职业。
- **说明**：
  - 日常抽取：池中无 **> 0** 权重时，空白权重为 100，等价于必不转职
  - 各职业权重之和超过 100 时，空白权重为 0；是否归一化实现期定
  - 离职抽取：雇佣结束瞬间角色**无职业**；判定时当前创值按 **0** 计；可选候选至少一门（首版拾荒者无任职条件作保底）
  - 转职与土地、占格无关，见 [characters.md](characters.md)

## 与其它概念的分工

| | 转职意愿计算器·分数模式 | 转职意愿计算器·议价模式 | 建筑估值 |
|--|----------------------|----------------------|----------|
| 问的问题 | 转职权重多少 / 抽中哪门自由职业 | 愿以何**金额**（日薪）接受岗位 | 这栋楼**客观值多少** |
| 得分范围 | **所有因素**综合得分 | **除创值比较外**的得分 + 反解金钱 | 估值金额 |
| 因职业类型 | 雇佣=佣金，生产类=产出市值 | 仅雇佣场景 | 不适用 |
