## P0 — 闭环缺口（无则难以跑通模拟）

### D03 建筑主人与土地产权

- **写入目标**：[structures.md](structures.md)
- **已决**（见 [needs.md](needs.md)、[structures.md](structures.md)「占格清场」）：购地=付费取得建造占用权；**占格清场**后土地归领主；**无**领主回购；换房/误建/欠薪取消走清场。
- **仍待决**：
  1. **建筑主人**何时确立（竣工瞬间？购地后？）；
  2. 多格 Footprint **按格权属**混有购地格 + 购置格时，如何记录；
  3. **被覆盖**格无购地时，土地权从哪来？
- **阻塞**：购置结算、组合方案产权链、AI 选址约束里的「建筑主人」判定。

## P1 — 规则歧义（已定机制内的洞或冲突）

### D06 雇佣离职后转职权重全 ≤ 0

- **写入目标**：[characters.md](characters.md) + [labor-benefit.md](labor-benefit.md)
- **问题**：离职抽取无空白，但若所有自由职业权重 ≤ 0 则**不转职**——此时雇佣已结束，角色职业状态**未定义**。
- **阻塞**：解雇/竣工/欠薪后的角色状态机。
- **候选**：
  - A. 保底落回离职前自由职业
  - B. 强制随机抽一个自由职业（忽略 ≤0）
  - C. 保留原自由职业「记忆」直至下次成功转职

## 依赖关系（简图）

```
资源标签 ─→ 需求 / 预期库存；市价按品种
商品估值计算器 ─→ 众人中位数 ─→ 平滑市价 ─→ 早市 / 产出市值 ─→ 转职分数
旅行商人 ─→ 场内货币总量 / 估值样本（同常驻角色，不含领主）
浆果过剩（最美角落）─→ 领主审批 / 税收 / 早市等手段破局

建筑净收入（租金+营业−税−薪酬）─→ 建筑估值 ─→ 占格成交价
生活水平 ─→ 自建 / 租床 / 【食物】预期库存
占格清场 ─→ 土地归领主（无回购）

建筑估值 ─→ luxury-housing / 购置比价
领主审批流程 ─→ multi-tile-workshop / berry-glut
```
