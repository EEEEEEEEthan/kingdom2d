## P1 — 规则歧义（已定机制内的洞或冲突）

### D06 雇佣离职后转职权重全 ≤ 0

- **写入目标**：[characters.md](characters.md) + [labor-benefit.md](labor-benefit.md)
- **问题**：离职抽取无空白，但若所有自由职业权重 ≤ 0 则**不转职**——此时雇佣已结束，角色职业状态**未定义**。
- **阻塞**：解雇/竣工/欠薪后的角色状态机。
- **候选**：
  - A. 保底落回离职前自由职业
  - B. 强制随机抽一个自由职业（忽略 ≤0）
  - C. 保留原自由职业「记忆」直至下次成功转职

### D08 服务等级与商业冷启动（部分已决）

- **写入目标**：[structures.md](structures.md) + [needs.md](needs.md)
- **已决**：角色**每月**随机尝试投资可能盈利的商业建筑（首版先**酒馆**）；盈利估算与建造可负担见 [structures.md](structures.md)「商业建筑投资」「建造可负担判定」
- **未决**：是否允许「低服务等级先入住」、开局是否强制种子商业
- **阻塞**：开局布局、住房升级路径是否可达

## 依赖关系（简图）

```
资源标签 ─→ 需求 / 预期库存；市价按品种
商品估值计算器 ─→ 众人中位数 ─→ 平滑市价 ─→ 早市 / 产出市值 ─→ 转职分数
旅行商人 ─→ 场内货币总量 / 估值样本（同常驻角色，不含领主）
浆果过剩（最美角落）─→ 领主审批 / 税收 / 早市等手段破局

建筑净收入（租金+营业−税−薪酬）─→ 建筑估值 ─→ 占格成交价
生活水平 ─→ 自建 / 租床 / 【食物】预期库存
占格清场 ─→ 土地归领主（无回购）

建筑估值 ─→ luxury-housing / 购置比价
领主审批流程 ─→ multi-tile-workshop / berry-glut
```
